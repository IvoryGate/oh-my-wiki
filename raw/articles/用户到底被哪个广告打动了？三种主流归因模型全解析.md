## 用户到底被哪个广告打动了？三种主流归因模型全解析

想象一个典型的转化路径：你先是收到一封营销邮件，然后刷到一条推送，接着在App里看到一个优惠券，又在谷歌上搜到了它的广告……最终，你下单了。

这时，营销团队最想知道的问题是： **在这一连串的“攻势”中，到底是哪个环节最终促使你下定了决心？**

为了解答这个问题，数据科学领域发展出了多种方法，其中， **多触点归因（Multi-touch attribution, MTA）** 是最核心的技术之一。它试图在用户层面上，为转化路径上的每一个“触点”（广告、邮件等）分配合理的“功劳”。

MTA有点像一门“玄学”，因为我们永远无法知道用户决策的“绝对真相”。但尽管如此，我们依然有一些强大的数学工具来逼近这个真相。

本文将带你快速了解三种复杂度递增的主流MTA方法： **Shapley值、马尔可夫链和LSTM** ，并附上代码实践。

---

## 1\. 案例实战：准备我们的“用户旅程”数据

我们使用一个公开的Kaggle数据集，它包含了2847名用户在两天内的1万次互动数据，涉及6个营销渠道。

首先，我们需要对原始数据进行处理，将用户的零散触点整合成一条条完整的“ **用户旅程（Journey）** ”。

```
import pandas as pd

df = pd.read_csv('multi_touch_attribution_data.csv')

# 数据清洗和预处理
df.columns = [c.lower().replace(" ", "_") for c in df.columns]
df['timestamp'] = pd.to_datetime(df['timestamp'])
df['conversion'] = df['conversion'].map({'Yes': 1, 'No': 0})
df = df.sort_values(['user_id', 'timestamp']).reset_index(drop=True)

# 识别新的用户旅程
df['is_new_journey'] = ((df['user_id'] != df['user_id'].shift(1)) |
                        (df['conversion'].shift(1) == 1)).astype(int)
df['journey_id'] = df['is_new_journey'].cumsum()

# 将触点聚合成路径
paths = df.groupby('journey_id').agg({
    'user_id': 'first',
    'channel': lambda x: ' > '.join(x),
    'conversion': 'max'
}).reset_index().rename(columns={'channel': 'path'})

print(paths.head())
```

处理后，我们的数据变成了这样，每一行代表一个完整的用户旅程：

## 2\. 方法一：末次触点归因（Last-Touch Attribution）

这是最简单、最基础的归因模型，也是很多公司的起点。它的规则简单粗暴： **将100%的功劳分给导致转化的最后一个触点。**

```
# 按旅程分组，找到最后一个渠道和最终转化状态
df_lta = (df
            .groupby("journey_id").agg({"channel":"last", "conversion": "last"})
            .groupby("channel").agg({"conversion":"sum"})
            .reset_index()
)

# 计算每个渠道的功劳占比
df_lta["credit"] = df_lta["conversion"] / df_lta["conversion"].sum()

print(df_lta)
```

**结果：**

末次触点归因结果

在这个模型下，“直接流量（Direct Traffic）”是最大的赢家。但它的问题也很明显：完全忽略了路径上其他触点的贡献。

## 3\. 方法二：Shapley值（Shapley Value）

Shapley值源于合作博弈论，听起来很高深，但思想很直观： **一个参与者（触点）的贡献，等于他加入联盟（转化路径）后，为整个联盟带来的边际收益。**

它会考虑所有可能的触点组合（排列），计算每个触点在不同组合下的边际贡献，最后加权平均，得到一个相对公平的“功劳分配”。

我们可以将营销触点视为“玩家”，将“转化”视为博弈的胜利。利用现有的Python库，我们可以计算出每个渠道的Shapley值。

**结果：**

Shapley值归因结果

与末次归因相比，结果变化不大，但“展示广告（Display Ads）”的功劳略有上升，“推荐（Referral）”的功劳则有所下降。Shapley值提供了一个比简单规则更公允的视角。

## 4\. 方法三：马尔可夫链（Markov Chain）

这是本文介绍的第一个 **关注触点顺序** 的模型。马尔可夫链将用户的转化路径看作是一系列“状态”的转移。

例如，“看到邮件”是一个状态，“点击搜索广告”是另一个状态。模型会学习从一个状态转移到另一个状态的概率。

除了6个渠道状态，我们还定义了两个最终的“吸收态”： **转化（Conversion）** 和 **流失（Null）** 。

通过计算数据中所有路径的状态转移次数，我们可以构建一个 **转移概率矩阵P** 。

转移概率矩阵

马尔可夫链归因的核心思想是“ **移除效应（Removal Effect）** ”：

1. 1\. 计算整个系统的基础转化率。
2. 2\. 依次“移除”掉某一个渠道（比如“社交媒体”），假设所有原本会进入该渠道的路径都直接导向“流失”。
3. 3\. 重新计算移除该渠道后，整个系统的总转化率。
4. 4\. 基础转化率和移除后转化率的差异，就代表了这个被移除渠道的“功劳”。
```
# 计算移除效应的简化代码
def calculate_removal_effect(paths, channel, baseline_conversion):
    paths_after_removal = paths.copy()
    # 如果路径中包含该渠道，则认为它未转化
    paths_after_removal['conversion'] = paths_after_removal.apply(
        lambda row: 0 if channel in row['path'] else row['conversion'], 
        axis=1
    )
    
    conversion_after_removal = paths_after_removal['conversion'].sum() / len(paths_after_removal)
    removal_effect = 1 - conversion_after_removal / baseline_conversion
    return removal_effect

# ...对每个渠道进行计算...
```

**结果：**

马尔可夫链归因结果

结果与之前的方法依然很相似。但马尔可夫链有一个值得深思的地方：对“移除”的解释。

上面的方法是假设移除渠道后，路径就断了。但另一种解释是，原本要进入该渠道的流量，会按比例重新分配到其他渠道。这两种不同的解释会得到截然不同的归因结果，甚至可能给某些渠道分配 **负分** ！这提醒我们，在使用模型时，理解其背后的假设至关重要。

## 5\. 方法四：LSTM（长短期记忆网络）

最后，我们来尝试一种截然不同的深度学习方法。LSTM是一种特殊的循环神经网络（RNN），它非常擅长处理序列数据，比如我们的用户触点序列。

LSTM的核心是它有一个类似“记忆”的机制（单元状态），可以学习在长序列中哪些信息应该被保留，哪些应该被遗忘。

我们的思路是：

1. 1\. 将每个渠道看作一个“单词”，将用户的转化路径看作一个“句子”。
2. 2\. 训练一个LSTM模型来预测给定一个路径序列，用户是否会转化。
3. 3\. 在模型中加入 **注意力机制（Attention Mechanism）** 。这个机制能让模型在做预测时，“关注”到序列中最重要的部分。
4. 4\. **模型“关注”的权重，就可以被我们用作归因的“功劳”** 。
```
# LSTM模型定义（简化版）
import torch.nn as nn
import torch.nn.functional as F

class LSTMAttnAttributor(nn.Module):
    def __init__(self, num_channels, embed_dim=4, hidden_dim=32):
        super().__init__()
        # 嵌入层：为每个渠道学习一个向量表示
        self.embed = nn.Embedding(num_channels, embed_dim, padding_idx=0)
        # LSTM层：处理序列信息
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)
        # 注意力层：学习每个时间步的重要性
        self.attn = nn.Linear(hidden_dim, 1)
        # 输出层：预测转化概率
        self.output = nn.Linear(hidden_dim, 1)

    def forward(self, x):
        e = self.embed(x)
        h, _ = self.lstm(e)
        
        # 计算注意力分数
        scores = self.attn(h).squeeze(-1)
        # Softmax归一化，得到权重
        norm_scores = F.softmax(scores.masked_fill(x==0, -1e9), dim=1)
        
        # 应用注意力权重
        context = torch.sum(h * norm_scores.unsqueeze(-1), dim=1)
        
        # 预测概率
        prob = torch.sigmoid(self.output(context)).squeeze(-1)
        
        return prob, norm_scores # 返回预测概率和注意力权重
```

训练模型后，我们可以提取出模型在处理每个用户旅程时，分配给每个触点的注意力权重，然后将所有路径的权重进行汇总，得到最终的归因结果。

**结果：**

LSTM归因结果

LSTM给出的结果分布差异最大，它认为“推荐”渠道的功劳远超其他渠道。这可能是因为它捕捉到了序列中更复杂的模式。但需要注意的是，注意力权重高也可能意味着这个触点对结果有很大的 **负面影响** ，需要谨慎解读。

## 6\. 总结：到底该用哪种方法？

我们看到了，四种不同的方法给出了四种不尽相同的结果。

| 渠道 | 末次触点 | Shapley值 | 马尔可夫链 | LSTM |
| --- | --- | --- | --- | --- |
| **推荐** | 第2 | 第3 | 第1 | 第1 |
| **直接流量** | 第1 | 第1 | 第2 | 第3 |
| **搜索广告** | 第3 | 第2 | 第3 | 第2 |
| ... | ... | ... | ... | ... |

**那么，到底该如何选择？**

没有标准答案，但这里有一个实用的建议：

- • **默认选择Shapley值** ：它理论基础坚实，结果相对公平和稳定，是一个很好的基准。
- • **如果认为触点顺序很重要，选择马尔可夫链** ：它可以很好地捕捉渠道间的转移关系。
- • **如果除了触点序列，你还有很多其他用户信息（如客户分群、设备类型等）想要利用，选择LSTM** ：深度学习模型能融合更丰富的信息，挖掘更深层次的洞察。

多触点归因是一个复杂的挑战，但通过这些强大的模型，我们可以离“真相”更近一步，从而更科学地指导我们的营销决策。
