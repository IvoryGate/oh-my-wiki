# 中文技术文档写作规范

> 中文技术文档的写作与排版规范速查：文档体系、标题、段落、文本、标点、数值与参考链接。

## 文档体系

软件手册建议结构：

- **简介**（Introduction）：[必备] 产品和文档的总体说明
- **快速上手**（Getting Started）：[可选] 最快使用方式
- **入门篇**（Basics）：[必备] 使用教程（环境准备/安装/设置）
- **进阶篇**（Advanced）：[可选] 开发教程
- **API**（Reference）：[可选] 接口逐一介绍
- **FAQ**：[可选] 常见问题
- **附录**（Appendix）：[可选] Glossary / Recipes / Troubleshooting / ChangeLog / Feedback

**文件名规则**：不含空格；只用半角字符（不用中文）；建议小写；多词用半角连词线 `-`（`glossary.md`、`advanced-usage.md`）；`README`/`LICENSE` 可例外大写。

## 标题

- 分四级：一级=文章标题，二级=主要部分，三级=二级的小节，四级=三级的小节
- 一级标题下不能直接出现三级标题
- 避免孤立编号（同级标题只有一个时省略）
- 下级标题不重复上级标题名
- 谨慎使用四级标题；三级标题下有并列内容时优先用项目列表

## 段落

- 一段一个主题，中心句放段首，后续句子为其服务
- 段落 ≤ 7 行，最佳 ≤ 4 行
- 陈述肯定语气，避免感叹语气
- 段落间空行隔开，开头不留空白字符
- 引用第三方内容注明出处；全篇转载在开头显著位置注明作者出处并链接原文；外部图片标注来源

## 文本

### 字间距

- 全角中文与半角英文之间留一个半角空格
- 中文与数字之间空格可有可无，但全篇必须统一风格
- 英文单位与数字间留空隙（`16 GB`）
- 半角英文字符/数字与全角标点之间不留空格

### 句子

- 避免长句：单句/逗号构件尽量 ≤ 20 字，> 40 字不可接受；逗号分割长句总长 ≤ 100 字或 3 行
- 多用简单句和并列句，避免复合句
- 多用肯定句，避免否定句、双重否定
- 不用被动语态、非正式语言、冷僻生造文言词
- 用对"的/地/得"；代词指代必须明确；名词前少用形容词

### 英文处理

- 英文复数译中文时还原单数
- 外文缩写用半角圆点（`U.S.A.`）
- 英文省略号 `...` 改为中文 `⋯⋯`
- 英文书名/电影名用书名号《》
- 首次出现的英文词汇括号内给中文标注，之后直接使用缩写
- 专有名词首字母大写，非专有名词不大写

## 标点符号

- 中文语句用全角标点；整句为英文时用半角标点
- 点号不得出现在行首；点号不得出现在标题末尾
- **句号**：全角 `。`；句末括号加注时句号在括号外
- **逗号**：避免"一逗到底"
- **顿号**：中文并列词用 `、`（即使含英文），英文句用半角逗号
- **引号**：全角双引号 `""`，内层用单引号 `''`
- **括号**：补充说明用全角圆括号 `（）`，前后不加空格
- **冒号**：引出解释用全角 `：`，表示时间用半角 `:`
- **省略号**：`⋯⋯`（占两汉字、六个点），不与"等"同用
- **感叹号**：尽量不用，禁止连用
- **破折号**：占两个汉字位置；仅占一个汉字位置时前后留半角空格
- **连接号**：复合词/图表编号用半角 `-`；数值范围用 `～` 或 `—`（全角）

## 数值

- 阿拉伯数字一律半角
- 千位以上加千分号（4 位数可选）
- 货币：数字前加符号或数字后加中文名称（`$1,000` / `1,000 美元`）
- 数值范围用 `～`/`—`，带单位时两端都加单位（`132 kg～234 kg`）
- 增减表述：**了**=增量（增加了/降低了），**到**=定量（增加到/降低到）；**禁止"降低 N 倍"**
