# NLP模型演进与核心任务

> 自然语言处理由两条主线交织推进：任务侧不断扩展应用场景，模型侧持续升级技术底座；二者在"预训练 + 微调"范式上汇合。

## 背景

自然语言处理（NLP）研究如何让计算机理解和生成人类语言，处于计算机科学、人工智能与语言学的交叉地带。语言本身具有歧义性、上下文依赖和演化性，是 NLP 面临的核心挑战。

## 模型演进线

| 阶段 | 代表 | 关键突破 |
|------|------|----------|
| 统计方法 | n-gram、HMM | 用概率建模替代规则手写 |
| 词向量 | [[Word2Vec]] | 词的分布式表示，语义可计算 |
| 循环网络 | [[LSTM]] | 序列建模，门控缓解长距离依赖 |
| 注意力 | [[注意力机制]] | 按相关性加权聚合，突破定长瓶颈 |
| 全注意力架构 | [[Transformer]] | 完全并行的序列建模，底座级架构 |
| 预训练语言模型 | [[BERT]] / [[GPT]] | 预训练 + 微调范式，理解与生成分野 |
| 多模态 | CLIP、DALL-E | 从纯文本扩展到图文跨模态 |

演进逻辑：每一代都在解决上一代的核心瓶颈——RNN 串行难并行 → 注意力直连依赖 → Transformer 全并行 → 预训练吸收通用知识 → 多模态突破模态边界。其中 [[Seq2Seq]] 是承上启下的关键框架（编码器-解码器结构，引出注意力，后被 Transformer 取代）。

## 经典任务线

- [[文本分类]]：最基础的任务形态，新闻分类等场景的通用范式
- [[情感分析]]：分类任务在主观情感上的专门化，词典法 → 机器学习法 → 深度学习法三代方法
- [[命名实体识别]]：定位并分类人名/地名/机构名，信息抽取的入口
- [[关系抽取]]：在实体对之间识别语义关系，与 NER 共同构成知识图谱构建的上下游
- 文本相似度计算：余弦相似度、编辑距离等度量（raw 留档，未建页）
- 文本预处理：分词、清洗、向量化等基础设施（raw 留档，未建页）

## 两条线的交汇

- **实现方式切换**：注意力与 [[Transformer]] 出现后，各任务的模型实现从 RNN 系全面转向 Transformer 系
- **预训练 + 微调范式**：一套底座服务多任务——[[BERT]] 主导理解类任务（分类/NER/关系抽取），[[GPT]] 主导生成类任务
- **表示即能力**：[[Word2Vec]] 开始的"表示学习"思路贯穿始终，任务差异收敛为底座 + 任务头的组合差异
