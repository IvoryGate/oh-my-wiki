## 知识流转规则

```
raw/                # 原始资料入库
  │
  ↓ Agent 提取
  │
wiki/atoms/         # 原子知识（概念、实体）
  │
  ↓ 你实践使用
  │
workspace/          # 实践过程
  ├── Done/         # 单篇完成 → wiki/synthesis/howto 或 insights
  └── topics/       # 话题积累 → wiki/synthesis/topics
  │
  ↓ 沉淀成熟
  │
wiki/synthesis/     # 综合知识（带个人判断）
  │
  ↓ 认知深化时直接更新
  │
（保持 status 和变更日志）
```
