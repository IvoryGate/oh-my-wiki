# 奥威尔与赫胥黎

> 两种不同的警告：奥威尔害怕外部压迫，赫胥黎害怕内部欲望

尼尔·波兹曼在《娱乐至死》开头对比了两个著名的反乌托邦小说：《1984》与《美丽新世界》。

## 奥威尔的世界 (1984)

| 维度 | 内容 |
|------|------|
| 恐惧 | 有人禁止你读书 |
| 机制 | 无所不在的集权政府，真相被隐藏 |
| 结果 | 自由被剥夺，痛苦是控制人的手段 |
| 类型 | 外部压迫 |

## 赫胥黎的世界 (美丽新世界)

| 维度 | 内容 |
|------|------|
| 恐惧 | 就算有书可看，也没人愿意看了 |
| 机制 | 没有暴力镇压，只有永不停歇的娱乐和锁麻药物 |
| 结果 | 人们自愿放弃自由，爱上自己的压迫 |
| 类型 | 内部欲望 |

## 核心对比

| | 奥威尔 | 赫胥黎 |
|--|--------|--------|
| 恐惧什么 | 被剥夺信息 | 得到信息太多太烂 |
| 担心什么 | 有人烧书 | 我们不再需要书 |
| 真理状态 | 真理被隐藏 | 真理被淹没 |
| 人的状态 | 被迫失去自由 | 自愿放弃自由 |

## 波兹曼的判断

今天的现实是**赫胥黎的警告正在成真**：
- 我们没有遇到禁止读书的政府，但我们自己不愿读书
- 每天被信息轰炸，最后什么都不信
- 自愿把自己锁在屏幕前，在笑声中主动交出注意力
