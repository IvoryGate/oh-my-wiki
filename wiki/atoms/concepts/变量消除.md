# 变量消除

## 核心定义

变量消除（Variable Elimination）是概率图模型中精确推断的基本算法，通过对无关变量求和来计算目标变量的边缘概率。

## 基本思想

给定联合概率分布 $P(X_1, X_2, ..., X_n)$，计算某变量 $X_i$ 的边缘概率：

$$P(X_i) = \sum_{X_1} \sum_{X_2} ... \sum_{X_n} P(X_1, X_2, ..., X_n)$$

通过按顺序消除变量，避免计算完整的联合分布。

## 算法步骤

1. **识别**：确定需要消除的变量集合
2. **因子分解**：将联合分布分解为因子（factors）
3. **求和**：对非目标变量依次求和
4. **归一化**：将结果归一化为概率分布

## 复杂度

- 树宽（Treewidth）决定复杂度
- 树宽小 $\Rightarrow$ 高效
- 树宽大 $\Rightarrow$ 指数级复杂度

## 优缺点

| 优点 | 缺点 |
|------|------|
| 精确推断 | 时间复杂度指数于树宽 |
| 通用性强 | 重复计算 |
