# 参数学习

## 核心定义

概率图模型的任务包括表示、推断与学习。**学习任务**（model learning）把推断任务颠倒过来：推断时模型的结构和参数作为输入，学习则是**根据数据来构造出能够反映数据潜在规律的模型**。

由于概率图模型的构建依赖垂直领域的先验知识，节点数目多、规模大时纯人工构建的工作量惊人，因此把学习任务引入其中，可基于结构化数据高效计算网络的结构与参数。

## 与结构学习的分工

按学习对象不同，学习任务分为两类：

- **参数学习**（parameter learning）：在**已知图模型结构**的前提下估计其参数，也就是节点之间的条件概率，可以看成是个**数值优化问题**
- **结构学习**（structure learning）：在图模型完全未知的情况下先确定结构，再根据结构计算参数，可看成针对结构和参数的**联合优化**，可以存在单一的全局最优解

参数学习还可按模型结构分为**对贝叶斯网络的学习**和**对马尔可夫随机场的学习**。有向和无向的差异带来截然不同的方案：贝叶斯网络中每对节点都定义了归一化的条件概率分布，学习针对的是每个单独的局部；马尔可夫随机场的归一化通过全局化的划分函数完成，参数的全局耦合使任务不能分解成若干简单任务的组合，学习难度更大。

## 贝叶斯网络：全局分解为局部

最简单的参数学习问题是利用**完全观测**的数据估计贝叶斯网络的参数，网络结构中不存在隐变量。从频率主义出发，基于似然概率最大化估计参数——最大似然估计的目标是找到让现有数据出现概率（似然函数）最大的那组参数。

关键技巧是**似然函数的全局分解**（global decomposition）：

- 依据贝叶斯网络的局部特性，**全局似然函数可以拆解成一些独立的局部似然函数的乘积**，每个独立项对应网络中的一个条件概率分布
- 作用是**简化参数估计的运算**：可以单独对每个局部似然函数进行最大化而无需考虑其他局部结构，把各局部的最优参数合并，得到的就是全局似然函数的最优解

最简单而最具代表性的应用是**朴素贝叶斯**分类器：把似然函数改写成属性似然函数的乘积，就是基于朴素贝叶斯图结构的全局分解；在此基础上统计当属性取得不同取值时，归属于某个类别的样本在该类别所有样本中所占的比例。

结论：对完整观测的贝叶斯网络做参数估计，就是把传统的**最大似然估计**和**最大后验估计**应用到有向图模型这个特定场景；图模型的条件独立性进一步把全局优化分解为相互独立的局部优化。

## 马尔可夫随机场：必须整体优化

以最简单的 MRF `A – B – C` 为例，势函数为 φ₁(A, B) 和 φ₂(B, C)，划分函数 Z 等于两个势函数的乘积对 A、B、C 所有可能取值求和。给定数据 a, b, c 时，似然概率为

```
p(a, b, c) = φ₁(a, b) · φ₂(b, c) / Z
           = φ₁(a, b) · φ₂(b, c) / Σ φ₁(a, b) · φ₂(b, c)
```

对它最大化时**不能把两个势函数分开各自求解**：Z 由所有参数共同决定，任一势函数变化都会改变 Z。原文的比喻是——**划分函数就像一条履带，把两个因子像齿轮一样扣在一起，让两者必须作为一个整体来优化。**

解法与性质：

- 每个因子被改写为**对数线性**形式（变量集特征函数的指数加权求和），参数变成对数线性模型中的权重，通过对权重似然函数的最优化实现参数学习
- 利用划分函数关于待估计参数是凸函数这一条件，可证明对数似然函数是**单峰函数，只有全局最优而没有局部最优**；求全局最优等价于找对数似然函数梯度为 0 的那组参数，最优解将和真实模型完全匹配
- 但该准则**不能给出解析解**，必须借助梯度法等最优化方法求解

### 可分解与不可分解

若 MRF 的图结构是**弦图**（chordal graph，即无向图中任意长度大于 3 的环路里都至少存在一条弦——连接环路中不相交顶点的无向边），则它是**可分解的**（decomposable）：

- 可分解的 MRF 可划分成不同的团，每个团的势函数初始化为**经验边际函数**（empirical marginal）
- 若团与其他团存在公共节点，其势函数还要除以公共结点的经验边际函数
- 原文示例：团 X₁X₂X₃ 的势函数为 p̃(x₁, x₂, x₃)；团 X₂X₃X₄ 因共享 X₂、X₃，势函数为 p̃(x₂, x₃, x₄) / p̃(x₂, x₃)；团 X₂X₄X₅ 为 p̃(x₂, x₄, x₅) / p̃(x₂, x₄)；三者相乘就是整个模型的似然函数

图结构不可分解时，要借助更一般的方法——**迭代比例拟合**（iterative proportional fitting）：在给定经验边际的条件下求解未知的势函数，一个一个地去满足经验边际的约束，但满足下一个约束可能破坏上一个约束，所以需要**通过迭代来逼近所有的边际条件**。

### 降低运算成本的两条路

**MRF 的运算成本较高，既可以使用近似推理过程计算梯度，也可以使用其他目标函数来代替似然函数：**

- **近似推理**：把学习问题当成推断问题来解决
  - 传播近似推理：将信念传播算法应用在 MRF 的学习中
  - 抽样近似推理：通常借助 [[MCMC]]，用平稳分布作为参数后验分布的估计
- **替代目标函数**：伪似然函数、对比散度、最大间隔函数等；其中**对比散度**已被用于受限玻尔兹曼机的训练

## 四个要点

1. 参数学习是在已知模型结构的前提下估计其参数，可以看成是模型的训练
2. 贝叶斯网络的参数学习可以由整体分解为局部，在局部上应用最大似然估计或者最大后验估计
3. 马尔可夫随机场的参数学习不能分解，也不存在解析解，可以使用通用的迭代比例拟合方法找到全局最优解
4. 马尔可夫随机场的参数学习可以通过近似推理和目标函数替换加以简化

## 原文留下的问题

本讲关注的是**完备数据**基础上的参数学习。数据不完备时可能缺失某些变量的观测样本，或存在不能被观测的隐变量：**隐变量的情形可通过[[EM算法]]解决，而"缺失观测样本"的情形原文未展开**，仅留给读者查阅资料。
