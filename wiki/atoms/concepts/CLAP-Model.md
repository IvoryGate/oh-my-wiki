# CLAP模型

## 定义

CLAP模型是一种复盘方法论,包含四个环节的循环:对比(Comparison)、逻辑(Logic)、认知(Acknowledge)、规划(Project)。它既能优化做事细节,也能优化业务战略,适合VUCA时代的复杂环境。

## 四个环节

```
对比(Comparison) → 陈述结果,与目标对比 → 事实总结
    ↓
逻辑(Logic) → 梳理逻辑,解释差距 → 原因分析
    ↓
认知(Acknowledge) → 提出假设,修正理解 → 认知修正
    ↓
规划(Project) → 制定改进方案 → 未来优化
    ↓
(进入下一循环)
```

### 1. 对比(Comparison)

- 陈述结果
- 与最初设定的目标进行对比
- 对事实的总结

### 2. 逻辑(Logic)

- 梳理逻辑
- 解释结果和目标之间的差距
- 对原因的分析

### 3. 认知(Acknowledge)

- 提出假设
- 更新对业务和用户的理解
- 对认知的修正

### 4. 规划(Project)

- 制定改进规划
- 在实践中验证
- 对未来的优化
- 结果作为下一次循环的依据

## 核心优势

### 弥补 [[PDCA-Model]] 的局限

- PDCA优化做事标准,CLAP也能优化
- PDCA缺乏业务战略调整机制,CLAP具备此能力
- PDCA适合工业化时代,CLAP适合VUCA时代

### 弥补 [[PDF-Model]] 的局限

- PDF严重依赖复盘者个人能力
- CLAP在 [[OPTM-Framework]] 框架下细化颗粒度
- CLAP提高可复制性,普通人也能用出效果

## 与其他模型的关系

- **改进了** → [[PDCA-Model]] (增加了战略调整能力)
- **改进了** → [[PDF-Model]] (增加了可复制性)
- **属于** → [[FuPan]] 方法论体系
- **被简化为** → [[AAR-Model]] (敏捷场景)
- **实践框架** → [[OPTM-Framework]]

## 适用场景

- 综合的、复杂度高的业务复盘
- 时间跨度长的项目复盘
- 需要调整业务战略的场景
- 需要多人参与、互相赋能的组织

## 实战案例

### 烘焙公司提升利润率

**背景**: 营业额增长但利润率下降

**对比**: 利润率同比下降15%,定位问题在销售成本

**逻辑**: 通过价值链分析,发现"充2000送500"活动成本过高

**认知**: 提出假设 - 选择高额充值的都是忠实客户,砍掉活动不会影响总销售额

**规划**:
1. 老客户规则不变
2. 去掉"充2000送500"
3. 强化"充1000送150"

**结果**: 提升利润率,不影响现金流

## 关键洞察

> 复盘的本质是进化,复盘能力就是适应环境变化的能力。在VUCA时代,环境变化更快、更复杂,企业需要更多人参与复盘。
