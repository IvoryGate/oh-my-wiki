# 归因链接

> 广告素材背后的技术链接，用于追踪用户来源和行为

## 定义

归因链接是广告图片或视频等素材背后的技术链接。当用户与广告互动时，该链接会向 MMP 上报用户交互发生的行为，包括时间戳、GAID、User-agent、IP、网络环境等信息。

## 核心作用

1. **识别来源渠道**：知道用户从哪个广告平台或渠道进入
2. **追踪用户行为**：监测点击、安装、打开应用等行为
3. **统计广告效果**：据此优化投放策略

## 两种类型

### 静态归因链接

- 参数固定，不会根据用户或上下文动态调整
- 适用于内容简单、无需精细化追踪的场景
- Example: `https://example.com/track?campaign_id=123&source=facebook`

### 动态归因链接（主流）

- 参数在用户点击时实时动态生成
- 可以根据用户位置、设备类型、广告系列等自动填充
- Example: `https://example.com/track?campaign_id={campaign_id}&source={source}&ip={ip}&device_model={device_model}`

## 核心参数

| 参数 | 含义 |
|------|------|
| pid | 广告渠道唯一标识符 |
| c | Campaign Name |
| af_adset | 广告组名称 |
| af_ad | 广告名称 |
| af_click_lookback | 点击归因窗口期，默认7天 |
| af_cost_value | 消耗金额 |
| af_media_type | 投放来源（app/web） |

## 窗口期规则

> 归因链接中设置的窗口期会覆盖后台默认设置

例如：后台设置为7天，但链接中手动设置为14天，则以链接中设置为准。

## 注意事项

1. 部分 Ad Network 会使用硬编码字段填充，以达到其目的（如写死 cost_value）
2. 代理需要与 Ad Network 完成双向互证才能开启流量
3. API 数据优先级高于 S2S
