# 模型评估指标

## 核心定义

用训练数据集拟合出备选模型的参数，再用验证数据集选出最优模型后，就进入**模型评估**阶段：使用测试数据集，通过衡量模型在从未出现过的数据上的性能来估计泛化特性。原文以二分类任务为例说明各项度量。

## 基础指标

- **精度（accuracy）**：分类正确的样本占样本总数的比例
- **错误率（error rate）**：分类错误的样本占样本总数的比例
- 两者之和等于 1

## 医学检查的例子

原文沿用"贝叶斯视角下的机器学习"中的例子：检查准确率 95%（患者 95% 阳性、非患者 95% 阴性），该人群发病率 1%。

- Jo 检查结果呈阳性时，患病概率**只有 16%**；若完全按检查结果判定，每 6 个病人里就要误诊 5 个
- Jo 检查结果呈阴性时，患病概率为 **0.053%**（= 0.05 × 0.01 / (0.05 × 0.01 + 0.95 × 0.99)）

原文由此说明：假阳性通常只带来不必要的精神压力，假阴性却可能让患者错过最佳治疗时机，所以医学上本着"宁可错判，不能放过"的原则，**对假阴性的要求比对假阳性更加严格**。这也是数理统计把分类错误分为一类错误和二类错误的原因。

## 混淆矩阵

将正例误判为反例、反例误判为正例的代价常常不同，机器学习采用**混淆矩阵**（confusion matrix，也叫列联表 contingency table）区分不同划分结果，四类为：

| | 预测为正 | 预测为负 |
|---|---|---|
| 实际为正 | 真正例 TP | 假反例 FN（假阴性） |
| 实际为反 | 假正例 FP（假阳性） | 真反例 TN |

- 假正例：样例本身是反例而预测结果是正例
- 假反例：样例本身是正例而预测结果是反例

## 查准率与查全率

- **查准率 P**（precision，也叫正例预测值 PPV）= TP / (TP + FP)，表示真正例占所有预测结果为正例的样例的比值，即模型预测结果的准确程度
- **查全率 R**（recall，也叫真正例率 TPR）= TP / (TP + FN)，表示真正例占所有真实情况为正例的样例的比值，即模型对真实正例的判断能力

通俗地说：**查准率要求把尽可能少的真实负例判定为预测正例，查全率要求把尽可能少的真实正例判定为预测负例。**

两者一般是鱼和熊掌不可兼得：以青光眼诊断依赖眼压值为例，阈值设高可保证被诊断的都是真正病人、查准率高，却会把症状不明显的初期患例划为正常，查全率大幅下降；阈值设低则查全率接近 100%，确诊病例中混入大量疑似患者，查准率大幅下降。

**P-R 曲线**把查准率和查全率画在同一平面直角坐标系内，表示模型可以同时达到的两者的水平。若一个模型的 P-R 曲线完全包住另一个，前者全面优于后者；更普遍的情况是各有优劣，需按任务特点选择。P-R 曲线在点 **(1, 1)** 上达到最优性能。

## ROC 曲线与 AUC

**受试者工作特征曲线**（receiver operating characteristic curve）简称 ROC，名字来源于其原始用途——判断雷达接收到的信号到底是敌机还是干扰。在机器学习中，样例共同符合一个由正例、反例各自分布叠加而成的混合分布，分类器的性能取决于两个概率分布的分离程度。

- **ROC 曲线描述真正例率与假正例率之间的关系，也就是收益（真正例）与代价（假正例）之间的关系**
- 假正例率 **FPR = FP / (FP + TN)**；ROC 空间以 FPR 为 X 轴、TPR 为 Y 轴
- 由 (0,0)、(0,1)、(1,0)、(1,1) 围成的正方形中，(0,0) 到 (1,1) 的对角线叫**无识别率线**，描述以 0.5 概率判正例的随机猜测模型（TPR 与 FPR 处处相等）。左上方 TPR > FPR、优于随机猜测；右下方劣于随机猜测
- **完美模型体现在 (0,1) 点**：FPR = 0 意味着没有假正例、没有负例被掺入；TPR = 1 意味着没有假负例、没有正例被遗漏
- 硬分类模型（如[[决策树]]直接输出类别）的 ROC 曲线退化为单个点；软分类模型（如[[朴素贝叶斯]]输出类别概率）每个阈值对应一个点，整条曲线是离散点连成的折线

ROC 曲线越靠近左上方性能越好；完全包住另一条则优于对方。多数情况下没有全方位碾压，需要 **ROC 曲线下面积 AUC**：

- AUC 在 0 到 1 之间；无识别率线的 AUC = 0.5，这样的模型完全没有预测价值
- 调整阈值可让最优 AUC 大于 0.5；**若模型 AUC 比 0.5 还小，可以通过求解其镜像（反转分类结果）获得优于随机猜测的结果**
- AUC 的意义不仅限于求面积，还能提供其他信息

**等精度线**（iso-accuracy lines）：若已知真实正例比例 pos、真实负例比例 1-pos，模型精度可表示为 `pos · TPR + (1-pos) · (1-FPR)`。精度相同的模型落在同一条直线上（原文给出的斜率为 (1-pos)/pos，即负例与正例的比值）。据此，正负例比例可作为先验信息指导模型选择：若比例约为 2:1，在 ROC 空间作一条斜率为 1/2 且经过 (0,1) 的直线并向右下方平行移动，与 ROC 曲线的交点即适用于该先验的最优模型，其精度等于交点所在直线的截距（与 TPR 轴的交点）。

## 四个要点

1. 二分类中模型性能度量的基本指标是精度和错误率，两者之和为 1
2. 混淆矩阵是 2 × 2 的性能度量矩阵，元素分别是真正例、假正例、假反例、真反例的数目
3. P-R 曲线表示查准率与查全率的关系，曲线在点 (1, 1) 上达到最优
4. ROC 曲线表示真正例率与假正例率的关系，曲线在点 (0, 1) 上达到最优
