# 特征工程

## 核心定义

对原始特征进行变换和选择，提升模型性能。

## 主要操作

| 操作 | 说明 |
|------|------|
| 标准化 | $x' = (x-\mu)/\sigma$ |
| 归一化 | $x' = (x-x_{min})/(x_{max}-x_{min})$ |
| 编码 | 类别 → 数值 |
| 离散化 | 连续 → 分箱 |

## 特征选择

- 过滤法
- 包装法
- 嵌入法
