# 随机森林

## 核心定义

随机森林（Random Forest）= Bagging + 决策树 + 随机特征选择。

## 算法特点

1. **Bagging**：Bootstrap 采样训练多棵树
2. **决策树**：每棵树完全生长
3. **随机特征**：节点分割时随机选择特征子集

## 优势

| 特性 | 说明 |
|------|------|
| 并行训练 | 高效 |
| 抗过拟合 | 平均降低方差 |
| 处理缺失值 | 天然支持 |
| 无需剪枝 | 完全生长 |

## 与 GBDT 对比

| 方面 | 随机森林 | GBDT |
|------|---------|-------|
| 基学习器关系 | 并行 | 序列化 |
| 树深度 | 完全生长 | 限制深度 |
| 输出方式 | 投票/平均 | 累加预测 |
