# 线性回归

## 核心定义

**线性回归** 用属性的线性组合预测连续输出。

## 模型形式

$$y = \mathbf{w}^T \mathbf{x} + b$$

## 参数估计

| 方法 | 说明 |
|------|------|
| 最小二乘法 | MSE 最小化 |
| 最大似然估计 | 似然度最大化 |

## 类型

| 类型 | 说明 |
|------|------|
| 一元线性回归 | 单个特征 |
| 多元线性回归 | 多个特征 |
