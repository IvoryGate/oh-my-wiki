# 瀑布模型

> 传统软件过程模型，按阶段顺序推进

## 流程

```
需求 → 设计 → 实现 → 测试 → 交付 → 维护
```

## 特点

- 阶段性强，分工协作清晰
- 只能单向流转，变更成本高
- 周期长，大项目风险高

## 衍生模型

- V模型：测试提前介入
- 增量模型：分批交付
- 螺旋模型：风险驱动迭代
