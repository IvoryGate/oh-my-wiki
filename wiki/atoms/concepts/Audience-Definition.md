## 定义

受众定义是增长的核心起点，需要在**增长的语言体系**下描述目标用户。

## 常见误区

| 错误思维 | 问题 |
|----------|------|
| 产品相似 = 受众相似 | 产品设计角度 ≠ 增长角度 |
| 玩法相似 = 受众相似 | 忽视用户行为差异 |
| 名字相似 = 受众相似 | 表面特征误导 |

## 三个核心问题

### 1. 如何正确描述核心受众？

关键：**用 Network 的语言体系**

- 流量侧定向体系：app 来源、机型、网络、国家
- 用户/产品标签体系：每个 Network 有自己的标签

> Network 会告诉你：我不要你觉得，我要我觉得。

### 2. 用户会在哪里出现？

- 了解 Network 认为和你相近的产品/标签
- 用户往往在这些产品/标签下出现

### 3. 如何尽可能覆盖？

1. 选择多个 Network 同时开始
2. 通过工具了解适合但未覆盖的 app
3. 在有价值流量起量：
   - 定向提价
   - 与 Network 合作冷启动
4. 一个 Network 起量后，其他 Network 也会开始起量

## 核心原则

> 如果你能清楚描述：我的产品适合在哪个 Network 买量，量大概来自哪些流量，哪里流量价值最高，什么用户标签...说明你对这个 Network 的认知达到了相当高的程度。
