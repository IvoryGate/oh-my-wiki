# LSTM

## 核心定义

LSTM（Long Short-Term Memory，长短期记忆网络）是循环神经网络（RNN）的一种改进架构，专门设计来解决标准 RNN 的长期依赖问题。它在 RNN 基础上引入三个门控机制和一个记忆单元，通过选择性记忆控制信息的保留与丢弃，从而以门控机制缓解梯度消失对长距离依赖建模的影响。LSTM 是 [[深度学习]] 中处理文本、语音、时间序列等序列数据的经典模型。

## RNN 的背景与梯度问题

RNN 的核心是循环连接：每个时间步的输入 = 当前数据 + 上一步的隐藏状态（Hidden State），输出不仅依赖当前输入，还依赖之前所有步骤的上下文。

**RNN 的优势**：

- 能处理变长序列，理论上可记住任意长度的历史
- 参数共享：同一组权重用于所有时间步

**RNN 的缺点（LSTM 的改进动机）**：

- 梯度消失/爆炸问题，难以学习长期依赖
- 计算效率较低，无法并行处理时间步

标准 RNN 每个时间步对隐藏状态做整体重写，信息在长序列传递中容易衰减丢失。

## 三个门与记忆单元

LSTM 引入三个门控机制和一个记忆单元：

| 组件 | 功能 |
| --- | --- |
| 遗忘门（Forget Gate） | 决定丢弃哪些旧信息 |
| 输入门（Input Gate） | 控制新信息的流入 |
| 输出门（Output Gate） | 控制输出的信息量 |
| 记忆单元（Cell State） | 保存长期状态 |

单步计算流程（伪代码思路，完整实现可参考来源教程）：

1. 遗忘门经 sigmoid 输出 0-1 权重，与上一时刻记忆单元相乘，决定保留多少旧信息
2. 输入门与候选记忆（tanh 生成）相乘，决定写入哪些新信息
3. 更新记忆单元：`c_next = 遗忘门 * c_prev + 输入门 * 候选记忆`
4. 输出门结合 `tanh(c_next)` 得到新的隐藏状态

三个门均使用 sigmoid 激活产生 0-1 之间的门控值，记忆单元的内容不会被每个时间步的操作直接修改。

## 如何缓解长距离依赖

LSTM 解决长期依赖问题的三条机制：

1. **选择性记忆**：遗忘门可决定保留或丢弃特定信息，避免无关内容干扰
2. **梯度通路**：记忆单元提供相对直接的梯度传播路径，梯度不必反复经过非线性压缩
3. **信息保护**：长期状态沿记忆单元较平滑地传递，缓解标准 RNN 逐时间步重写导致的梯度消失

**与 GRU 对比**（GRU 是 LSTM 的简化版）：

- LSTM 有 3 个门和独立记忆单元，GRU 只有更新门与重置门 2 个门
- LSTM 参数更多、训练较慢，大数据集上可能更好；GRU 更快，小数据集表现较好
