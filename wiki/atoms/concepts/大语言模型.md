# 大语言模型

## 核心定义

大语言模型（Large Language Model，LLM）是基于海量文本训练出来的深度学习模型，其本质是一个「预测下一个词」的概率模型：给定前面的文字，预测接下来最可能出现的内容。几乎所有现代 LLM 都基于 Transformer 架构，其核心是注意力机制（Attention），让模型在处理某个词时动态「关注」序列中其他相关词。ChatGPT、Claude、通义千问等产品底层都是 LLM。

## Token 化与基本结构

- 模型不按「字」或「单词」处理文本，而是按 Token（词元）处理：一个 Token 可能是一个汉字、一个英文单词，也可能是单词的一部分。
- 上下文窗口（Context Window）是模型一次能看到并处理的最大 Token 数量；上下文长度限制与 API 计费都按 Token 计算。
- 参数量（Parameters）指模型内部可学习的权重数量，以 B（十亿，Billion）为单位，如 7B、70B。它在一定程度上反映规模与能力上限，但训练数据质量、架构设计同样关键。

## 训练链路

一个能自然对话的 LLM 通常经过多个训练阶段层层叠加能力：

- 预训练（Pre-training）：在海量无标注文本（网页、书籍、代码）上学习语言的统计规律，耗费算力最大，是能力基础，但此时模型还不擅长按指令做事。
- SFT（监督微调）：用人工标注的「问题—答案」对数据，教模型按人类指令回答问题。
- RLHF（人类反馈强化学习）：让人类对多个候选回答打分或排序，用反馈训练模型，使输出更有用、更诚实、更安全。
- 对齐（Alignment）是更宏观的目标，贯穿 SFT、RLHF 等环节；在通用模型上用领域数据继续训练则称为[[微调]]。

## Scaling Law（规模定律）

Scaling Law 是过去几年大模型成功的核心指导原则——在一定范围内，模型性能随着计算量、数据量、参数量的增加而可预测地提升。

- OpenAI 2020 年论文《Scaling Laws for Neural Language Models》系统阐述：三者扩大 N 倍时，损失值以 log(N) 方式下降，边际收益递减但持续投入仍有提升。
- Chinchilla 最优训练法则（DeepMind 2022）修正了早期做法：给定计算预算，参数量与训练数据量应按比例同步扩大——计算翻倍时两者各约扩大 1.4 倍。
- 局限与争议：边际收益递减（性能翻倍或需十倍百倍投入）、能力涌现不可预测、高质量文本数据总量有限可能触及数据天花板。

## MoE（混合专家模型）

MoE（Mixture of Experts）是一种让模型变大但不显著增加推理成本的架构设计。

- 模型内部包含多个「专家」子网络，每次处理输入只激活其中一部分参数，而非全部参与计算，做到「参数大、推理快」。
- 稠密模型每个 token 使用全部参数；MoE 是稀疏的，由门控网络决定每个 token 发给哪些专家，通常取权重最高的 Top-K 个并加权求和。
- 训练挑战在于负载均衡：若多数 token 都分给少数专家，其他专家得不到训练，模型容量就被浪费。
- 代表模型 Mixtral 8x7B：8 个 7B 专家、每 token 选 Top-2，实际使用约 14B 参数但总参数 47B，推理成本与 14B 稠密模型相当而性能接近 70B。
