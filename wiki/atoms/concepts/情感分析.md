# 情感分析

## 核心定义

情感分析（Sentiment Analysis）通过计算技术自动识别、提取和分析文本中的主观信息，判断作者对特定主题、产品或服务的态度是正面、负面还是中性。它是自然语言处理中最经典、应用最广泛的任务之一，本质上是一类特殊的分类任务。

## 任务类型

- **按分析粒度**：
  1. 文档级——整篇文档作为一个整体判断
  2. 句子级——分析单个句子的情感极性
  3. 方面级——针对文本提到的特定方面判断
- **按情感维度**：
  1. 二分类：正面 / 负面
  2. 三分类：正面 / 中性 / 负面
  3. 多分类：更细粒度（愤怒、高兴、悲伤等）
  4. 情感强度分析：量化情感的强烈程度

## 常用方法

三类主流方法，从规则到模型依次递进：

1. **基于词典**：依赖预构建情感词典（英文如 SentiWordNet、VADER，中文如知网 Hownet、大连理工大学情感词汇本体库），配合程度副词（非常 1.5、有点 0.8）与否定词调节分数。
   - 优点：无需训练数据、效率高、可解释性强
   - 缺点：难处理讽刺反语、依赖词典覆盖度、无法捕捉上下文
2. **基于机器学习**：用词袋、TF-IDF、N-gram 等特征训练分类器（朴素贝叶斯、SVM、逻辑回归），常结合情感词典特征。
3. **基于深度学习**：CNN、LSTM 与 BERT 等预训练模型直接从数据学习表示。

## 细粒度情感分析（ABSA）

方面级情感分析识别文本中提到的特定方面并判断其情感，核心子任务：

- **方面提取**：显式方面如「电池续航很好」→「电池」；隐式方面如「照片很清晰」→「摄像头」
- **情感分类**：对每个方面单独判断极性
- **实现方式**：
  - 流水线方法：先 CRF 提方面，再分类器判情感，模块清晰但有误差传播
  - 端到端方法：BERT-ABSA、AOA-LSTM，性能更好但需更多数据
  - 多任务学习：知识共享但任务平衡困难

## 评估与挑战

- **评估**：与分类任务一致，用准确率、precision / recall / F1（可交叉验证比较不同算法）
- **挑战**：上下文依赖、领域适应性、多语言差异、讽刺与反语检测
- **发展方向**：多模态情感分析、跨语言情感分析、情感原因提取、个性化情感分析
