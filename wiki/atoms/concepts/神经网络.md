# 神经网络

## 核心定义

人工神经网络（Artificial Neural Network）是对生物神经网络的模拟，通过层次化结构实现复杂模式学习。

## 基本单元：神经元

$$y = \sigma(\mathbf{w}^T \mathbf{x} + b)$$

其中 $\sigma$ 是激活函数。

## 层次结构

| 层次 | 作用 |
|------|------|
| 输入层 | 接收特征 |
| 隐藏层 | 特征提取 |
| 输出层 | 预测结果 |

## 激活函数

| 函数 | 表达式 |
|------|--------|
| Sigmoid | $1/(1+e^{-x})$ |
| Tanh | $(e^x - e^{-x})/(e^x + e^{-x})$ |
| ReLU | $\max(0, x)$ |
| Softmax | 多分类输出 |

## 学习算法

- 反向传播（Backpropagation）
- 梯度下降
