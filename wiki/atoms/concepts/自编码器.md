# 自编码器

## 核心定义

自编码器（Autoencoder）是一种无监督学习的神经网络，用于学习数据的压缩表示（编码），实现降维或特征提取。

## 结构

- **编码器（Encoder）**：将高维输入映射到低维潜在空间
- **解码器（Decoder）**：将低维表示恢复为原始维度
- **潜在空间（Latent Space）**：中间的低维表示

## 训练目标

最小化重构误差：$\min \|x - \hat{x}\|^2$

其中 $\hat{x}$ 是解码器对编码的重建结果。

## 类型

| 类型 | 特点 |
|------|------|
| 欠完备自编码器 | 潜在空间维度 < 输入维度，实现降维 |
| 过完备自编码器 | 潜在空间维度 > 输入维度，需加入稀疏约束 |
| 稀疏自编码器 | 约束大部分隐藏单元为 0 |
| 变分自编码器 (VAE) | 学习概率分布，生成新样本 |
| 去噪自编码器 | 从损坏输入恢复干净输出 |

## 与 PCA 的关系

若自编码器只有单个线性隐藏层，使用均方误差，则隐藏层权重等价于 PCA 的主成分。

## 应用

- 数据降维
- 特征提取
- 异常检测
- 图像去噪
- 生成模型
