# PDF模型

## 定义

PDF模型(Preview-Do-FuPan)是由联想集团创始人柳传志引入做事过程中的方法论,又称"柳传志环"。它将一件事情重复做三次:沙盘推演、执行、复盘。

## 三次行动

```
Preview(沙盘推演) → 做事前推演所有可能性 → 虚拟做
    ↓
Do(执行) → 方案落地执行 → 实际做
    ↓
FuPan(复盘) → 事后复盘总结 → 虚拟做
```

### 关键理解

**不是PDCA的变体**

- PDCA: 把一件事情分成4个环节
- PDF: 把一件事情重复做3次

**三次做的区别**

- 第1次沙盘推演:虚拟地做
- 第2次执行:实际地做
- 第3次复盘:虚拟地做

## 复盘部分的四个环节

```
目标 → 结果 → 分析 → 总结
```

### 1. 目标

- 当初设定的目标是什么
- 设定目标的原因是什么

### 2. 结果

- 对照目标评估工作成果
- 是完成了、没完成、还是部分完成

### 3. 分析

- 通过不停地追问
- 找到成功或失败的根本原因

### 4. 总结

- 继续深挖成功的经验
- 总结失败的教训
- **规律要经过其他案例验证**(避免偶然性)

## 核心特点

### 优化方式

**调整业务战略**

- 销售模式
- 盈利模式
- 目标客群
- 根据行业趋势、竞品策略、用户需求灵活调整

### 重大发现

> 规律要经过其他案例验证,从而避免偶然性因素

这是一个非常了不起的方法论发现

## 成功案例:联想PC业务

### 背景

2002年,戴尔在中国PC市场异军突起,联想市场份额急剧下降

### 初步判断

很多人认为:"直销模式比分销模式好",结论是变更销售模式

### 深度复盘

核心高层经过周密推演,得到关键战略洞察:

> 与戴尔的竞争,本质上是**组织效率和客户价值感受**的竞争

### 复盘结论

**问题1:内部沟通成本高、决策流程固化、反应慢**

解决:
- 结构扁平化
- 7个大区重组为18个分区
- 决策权下放
- 更高效响应市场

**问题2:戴尔直销优势**

解决:
- 销售模式调整为直销与分销结合
- 个人客户:直销模式
- 大客户和企业客户:增值服务更好的分销模式

### 结果

一年内夺回市场份额,到2020年全球和中国PC市场份额名列前茅

## 局限性

### 严重依赖复盘者个人能力

**需要的能力:**

- 摸爬滚打多年的行业经验
- 跨部门跨领域的大局观
- 洞察业务问题的关键能力

**需要的条件:**

- 老板充分的支持和信任
- 有魄力否定大部分人的错误认知
- 有底气坚持自己的看法

### 可复制性不强

- 这个人成功了,换一个人不一定成功
- 甚至这个人这次成功了,下一次也不一定成功
- 这样的机会注定非常稀缺

### VUCA时代的挑战

**市场碎片化和用户碎片化**

- 自上而下的业务规划和指令传达仍然重要
- 但光靠这一点已难满足用户需求
- 需要让更多员工参与洞察和满足用户需求

**组织趋势:**

- 结构扁平化
- 服务多元化
- 层级变少,高管变少
- 虚拟团队和行动小组变多
- 独立负责小业务的人变多

## 改进方向

### 需要的能力

- 让更多普通人用出效果
- 互相赋能
- 可复制的方法论

### 改进模型

[[CLAP-Model]] 在 [[OPTM-Framework]] 框架下弥补了PDF的局限:

- 颗粒度更细的流程和标准
- 降低对个人能力的依赖
- 提高可复制性

## 与其他模型的关系

- **引入者** → 柳传志(联想集团创始人)
- **被改进** → [[CLAP-Model]] (提高可复制性)
- **对比参照** → [[PDCA-Model]]
- **属于** → [[FuPan]] 方法论体系

## 适用场景

- 需要调整业务战略的复盘
- 有经验丰富的高层领导参与
- 组织层级分明、自上而下的环境

## 不适用场景

- 需要基层员工广泛参与的复盘
- 缺乏经验丰富的复盘者
- 需要快速复制的方法论
