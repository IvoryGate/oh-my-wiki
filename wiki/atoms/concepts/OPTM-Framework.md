# OPTM框架

## 定义

OPTM框架是 [[CLAP-Model]] 的实践框架,包含三个层级:组织(Organization)、流程(Process)、工具&方法(Tools&Methods)。它从人、事、物三个角度充实了CLAP模型,提高可复制性和落地能力。

> OPTM是英文单词Optimize的缩写,意思是优化,正好是复盘的目的。

## 三层结构

```
组织层(Organization) → 人 → 复盘团队
    ↓
流程层(Process) → 事 → 三阶段流程
    ↓
工具&方法层(Tools&Methods) → 物 → 实用工具和方法
```

### 1. 组织层(Organization)

**人的层级** - 专业复盘团队

#### 团队性质

- **虚拟组织**: 成员专门但不专职做复盘
- 类似人民代表大会形式
- 正式称谓:"复盘组委会"
- 非正式称谓:"复盘小组"

#### 团队职责

- 组织重大事件或阶段性任务的复盘
- 提升认知水平
- 帮助公司和员工成长

#### 具体工作

- 推动复盘按部就班进行
- 完善和优化复盘流程、工具和方法

#### 角色配置

| 角色 | 职责 |
|------|------|
| 主持人 | 主导整个复盘流程 |
| 引导师 | 负责提问和逻辑引导 |
| 陈述人 | 整理和介绍各项资料 |

### 2. 流程层(Process)

**事的层级** - 标准复盘流程

#### 三阶段流程

```
会前准备 → 复盘会议 → 会后执行
```

##### 阶段一:会前准备

- 筹建团队
- 分配任务
- 整理资料
- 确定主题、场地、人员、物料、流程、规则
- **CLAP的信息输入部分**

##### 阶段二:复盘会议

- 陈述结果,对比目标
- 梳理逻辑,分析原因
- 提出假设,修正认知
- **CLAP的CLA环节**(重头戏)

##### 阶段三:会后执行

- 会议记录同步
- 资料归档
- 制定规划
- 评估效果
- 实践验证
- **CLAP的P环节和信息输出部分**

### 3. 工具&方法层(Tools&Methods)

**物的层级** - 实用工具和方法

#### 工具 vs 方法

| 类型 | 形式 | 示例 |
|------|------|------|
| 工具 | 具体形式 | 表格、思维导图 |
| 方法 | 抽象形式 | 原则、思路 |

#### 工具示例

- 岗位画像设计表
- 价值链分析图
- 成本拆解表
- 流程图

#### 方法示例

- 选人原则
- 关键事件法
- 情境还原法
- 假设验证法

## 核心价值

### 提高可复制性

- **颗粒度更细**: 每个环节都有具体工具和方法
- **降低能力门槛**: 普通人也能用出效果
- **互相赋能**: 团队成员共同成长

### 弥补 [[PDF-Model]] 的局限

- PDF严重依赖复盘者个人能力
- OPTM提供标准流程和工具
- 让更多人能参与复盘

## 与CLAP模型的关系

- **框架支撑**: OPTM是CLAP的落地框架
- **三层充实**: 从人、事、物三个角度充实CLAP
- **流程对应**: 三阶段流程与CLAP四环节对应

```
会前准备 → 信息输入
复盘会议 → CLA环节(对比、逻辑、认知)
会后执行 → P环节(规划) + 信息输出
```

## 实战要点

### 精简配置

对于小型复盘,可采用精简配置:
- 1位主持人(公司总经理)
- 1位引导师(外部顾问或内部专家)
- 2-3位陈述人(各职能部门代表)

### 快速准备

如果资料现成,会前准备可压缩到30分钟内

### 评估维度

- **效率**: 流程开放高效,达成结论,不超时
- **氛围**: 参与度高,态度正面,关注解决问题
- **信心**: 团队对目标达成有信心
