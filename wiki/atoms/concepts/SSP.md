# SSP 供应方平台

> Supply-Side Platform，管理发布商变现的平台

## 定义

SSP（Supply-Side Platform）是广告技术栈中的供应方平台，帮助发布商（Publisher）管理广告位库存和变现。

## 核心角色

- **Supply 端**：代表发布商利益
- **对接 ADX**：向广告交易所提供广告位
- **变现优化**：最大化广告位收益

## 工作流程

```
用户访问 → SSP 发起 Ad Request → ADX → DSP 出价 → ADX 竞价 → 广告展示
```
