# 马尔可夫链

## 核心定义

**马尔可夫链**（Markov chain）是满足**马尔可夫性**的随机过程：未来状态只依赖当前状态，与更早的历史无关，且状态间转移概率恒定。

$$P(X_{n+1} = j \mid X_n = i, X_{n-1} = i_{n-1}, \dots) = P(X_{n+1} = j \mid X_n = i) = p_{ij}$$

## 关键概念

| 概念 | 说明 |
|------|------|
| 状态转移矩阵 P | 记录所有状态间转移概率，p_ij 为 i→j 的概率 |
| 分布向量 π⁽ⁿ⁾ | n 时刻各状态占比，满足 π⁽ⁿ⁺¹⁾ = P·π⁽ⁿ⁾ |
| 稳态分布向量 | 满足 Pπ = π 且归一化的分布，即矩阵特征值 1 的特征向量 |
| 不可约 | 任意两状态间都能在有限步内以正概率到达 |
| 非周期 | 不存在固定的回归周期 d ≥ 2 |

## 马尔可夫极限定理

不可约 + 非周期的马尔可夫链，从任意初始分布出发都会收敛到**唯一**的稳态分布：

$$\lim_{n \to \infty} P^n \cdot \pi^{(0)} = \pi$$

## 应用

- [[隐马尔可夫模型]]：隐藏状态按马尔可夫链传播
- [[MCMC]]：构建平稳分布 = 目标分布的马尔可夫链
- [[马尔可夫链归因]]：广告多渠道归因中的马尔可夫链方法
- PageRank：网页超链接构成的马尔可夫链
- 《联邦党人文集》作者归属：用词习惯的转移概率推断
- 社会现象建模：阶层流动、公司人才结构、王朝兴衰、扶贫困境、心理复发

## 启示：结构性宿命

不改变转移概率（系统结构），只改变初始状态是徒劳的——系统总会收敛到同一稳态。**要跳出"宿命"，必须改变系统的底层机制和结构。**
