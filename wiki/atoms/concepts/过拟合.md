# 过拟合

## 核心定义

过拟合（Overfitting）指模型在训练数据上表现良好，但在测试数据上泛化能力差的现象。

## 表现

- 训练误差小，测试误差大
- 模型过于复杂，记住了训练数据的噪声

## 原因

1. 训练数据不足
2. 模型复杂度过高
3. 训练时间过长

## 解决方法

| 方法 | 说明 |
|------|------|
| 增加数据量 | 根本解决 |
| 正则化 | L1/L2 约束参数 |
| Dropout | 随机失活神经元 |
| 早停 | 验证集性能下降时停止 |
| 交叉验证 | 选择最优超参数 |

## 与欠拟合对比

| 问题 | 训练误差 | 测试误差 | 解决方案 |
|------|----------|----------|----------|
| 过拟合 | 低 | 高 | 增加数据、正则化、简化模型 |
| 欠拟合 | 高 | 高 | 增加模型复杂度、增加特征 |
