# 程序化广告

> SSP、ADX、DSP 通过实时竞价（RTB）完成广告位买卖的生态体系

## 生态角色

| 角色 | 全称 | 代表立场 | 职责 |
|------|------|----------|------|
| SSP | Supply-Side Platform | 发布商 | 管理广告位库存，最大化广告位收益 |
| ADX | Ad Exchange | 中立枢纽 | 连接买卖双方，组织并管理竞价 |
| DSP | Demand-Side Platform | 广告主 | 管理投放需求，根据用户特征实时出价 |
| DMP | Data Management Platform | 数据方 | 数据管理平台，辅助出价决策 |

## 一次广告展示的完整流程

```
用户访问页面 → SSP 发起 Ad Request → ADX 转发给多家 DSP → DSP 根据用户特征出价 → ADX 竞价（通常二价拍卖）→ 胜出广告展示
```

## 各角色详解

### SSP 供应方平台

SSP 是广告技术栈中的供应方平台，帮助发布商（Publisher）管理广告位库存和变现。

- **Supply 端**：代表发布商利益
- **对接 ADX**：向广告交易所提供广告位
- **变现优化**：最大化广告位收益

### ADX 广告交易所

ADX 是连接广告买卖双方的交易平台，负责管理 DSP 和 SSP 之间的广告位交易。

1. **接收请求**：从 SSP 接收广告位请求
2. **转发请求**：将请求发送给多家 DSP
3. **竞价管理**：组织竞价，选择胜出者
4. **结果反馈**：告知 DSP 竞价结果
5. **下发广告**：将胜出广告发送给用户设备

竞价阶段：

| 阶段 | 说明 |
|------|------|
| Request | SSP 向 ADX 发送广告位请求 |
| Auction | ADX 向 DSP 发送竞价请求 |
| Response | DSP 返回出价和广告物料 |
| Win | ADX 选出最高出价者 |
| Fill | 下发广告物料 |
| Show | 广告展示 |

### DSP 需求方平台

DSP 是广告技术栈中的需求方平台，帮助广告主管理和优化广告投放。

- **Demand 端**：代表广告主利益
- **对接 ADX**：从广告交易所获取流量
- **出价决策**：根据用户特征实时出价

与 ADX 的配合：ADX 发出广告请求 → DSP 根据用户信息出价 → ADX 汇总所有 DSP 出价，选择最高者。

## RTB 实时竞价

RTB（Real-Time Bidding）是一种程序化广告技术，允许广告主在广告位展示的瞬间实时出价竞拍。

**二价拍卖**：胜出者支付**第二高**出价，鼓励广告主报出真实价格。
