## 文件与搜索

### fd — 比 find 快 10 倍的查找器

`find` 的参数设计很老旧，`fd` 重新设计了体验，开箱即用。

```shell
# 递归查找名称含 config 的文件
fd config

# 大小写不敏感（默认智能大小写）
fd config -i

# 查找特定扩展名
fd -e md
fd -e lua -e py

# 查找并执行命令（-x = 对每个结果执行）
fd -e jpg -x convert {} {.}.png
# {.} 是去掉扩展名的路径

# 在指定目录下搜索
fd config ~/.config

# 排除目录
fd config -E .git -E node_modules

# 查找空目录
fd --type empty --type directory

# 查找最近修改的 5 个文件
fd --changed-within 10min -t f | head -5
```

特点：遵守 `.gitignore`、默认递归、彩色输出、智能大小写。

### ripgrep（rg）— 比 grep 快 10 倍的搜索器

```shell
# 在代码里搜索 pattern
rg function_name

# 搜索特定文件类型
rg -t rust unsafe
rg -t md "核心概念"

# 只显示文件名（-l）
rg -l "TODO" src/

# 显示匹配行号（默认就有）
rg "class.*Handler"

# 搜索但不包括某些文件
rg pattern -g '!*.min.js'

# 反向匹配（不包含的行）
rg -v "debug"

# 替换（只显示结果，不改文件）
rg "old_text" --replace "new_text"

# 搜索并替换（需要 GNU sed 或搭配 rpl）
rg -l "old" | xargs sed -i 's/old/new/g'
```

特点：遵守 `.gitignore`、默认递归、彩色输出、支持 PCRE2 正则。

### fzf — 终端模糊搜索器

fzf 不是取代某个命令，而是**增强所有命令**——你在终端里的交互方式会因此改变。

```shell
# 交互式搜索文件
fzf

# 配合 fd，搜索并打开
vim $(fd -e md | fzf)

# 历史命令搜索（这是最常用的场景）
# 绑定 Ctrl+R 后：
# 按 Ctrl+R → 输入关键词模糊搜索 → Enter 执行

# 搜索并切换目录
cd $(fd -t d | fzf)

# 搜索进程并 kill
kill -9 $(ps aux | fzf | awk '{print $2}')

# 搜索 Git 分支并切换
git checkout $(git branch | fzf)
```

```shell
# .zshrc 中推荐的 fzf 配置
source <(fzf --zsh)
# 绑定:
#   Ctrl+T   → 在当前命令位置插入选中的文件/目录
#   Ctrl+R   → 模糊搜索历史命令
#   Alt+C    → cd 到选中的目录
```

### bat — 带语法高亮的 cat

```shell
# 查看文件（自动语法高亮）
bat file.py

# 显示行号
bat -n file.py

# 只显示特定行范围
bat file.py --line 10:30

# 作为 cat 的别名（不显示行号 + 不分页）
alias cat='bat --plain'

# 对比多个文件
bat file1.py file2.py

# 配合 fzf 预览文件
fd -e md | fzf --preview 'bat --color=always {}'
```

### eza — 现代化的 ls

```shell
# 替代 ls -la（彩色输出，文件类型图标）
eza -la

# 目录树
eza --tree

# 按大小排序
eza -la -s size

# 只显示目录
eza -D

# 显示 git 状态
eza -la --git
```

### zoxide — 智能 cd

```shell
# 自动学习你 cd 过的目录
z config    # 跳转到 ~/.config，即使当前不在那附近
z wiki      # 跳转到任何名字含 wiki 的目录
zi conf     # 交互式选择

# 常用场景
z -         # 回到上一个目录（类似 cd -）
z foo bar   # 跳转到同时匹配 foo 和 bar 的目录
```

zoxide 的 `z` 和 `zi` 是真正的效率提升——不再需要反复 `ls` + `cd`。

## 文本处理

### jq — JSON 的命令行处理器

```shell
# 格式化 JSON
cat data.json | jq .
curl api.example.com | jq .

# 提取字段
jq '.name' data.json
jq '.users[].email' data.json

# 过滤
jq 'select(.age > 18)' data.json

# 输出为 TSV
jq -r '["Name", "Age"], (.users[] | [.name, .age]) | @tsv' data.json

# 修改 JSON
jq '.count += 1' data.json

# 管道输出
curl api.com/users | jq -r '.[] | "\(.id) \(.name)"'
```

### yq — YAML 的命令行处理器（类似 jq）

```shell
# 读取 YAML 字段
yq '.version' config.yaml

# 修改并保存
yq '.debug = true' -i config.yaml

# YAML ↔ JSON
cat config.yaml | yq -o json
cat config.json | yq -P   # -P = pretty print
```

### sed — 流编辑器（一行搞定替换）

```shell
# 替换第一个匹配
sed 's/old/new/' file.txt

# 替换所有匹配（-g）
sed 's/old/new/g' file.txt

# 原地修改（-i）
sed -i 's/old/new/g' file.txt

# 备份后修改（macOS 需要给 -i 传参数）
sed -i.bak 's/old/new/g' file.txt

# 只打印匹配行（-n）
sed -n '/error/p' log.txt

# 删除匹配行
sed '/debug/d' file.txt

# 多文件替换
sed -i 's/foo/bar/g' src/*.js
```

> macOS 的 sed 是 BSD 版，和 GNU sed 有差异。`-i` 要传空字符串：`sed -i '' 's/old/new/g'`，或者装 gnu-sed。

### awk — 按列处理文本

```shell
# 打印第 1 列和第 3 列
awk '{print $1, $3}' file.txt

# 以逗号分隔
awk -F, '{print $1, $2}' data.csv

# 过滤行（第 3 列大于 100）
awk '$3 > 100' data.txt

# 统计总和
awk '{sum += $1} END {print sum}' numbers.txt

# 格式化输出
awk '{printf "%-20s %s\n", $1, $2}' file.txt
```

### sponge — 吞噬输入再写出

`sponge` 来自 `moreutils` 包，解决一个常见问题：你想原地修改文件，但管道重定向会把文件先清空。

```shell
# 错误的做法（先清空了 file.txt）
cat file.txt | grep pattern > file.txt  # 文件会变空！

# 正确的做法
cat file.txt | grep pattern | sponge file.txt

# 结合 jq 修改 JSON 文件
cat config.json | jq '.key = "value"' | sponge config.json

# 安装
brew install moreutils
```

## 系统监控

### htop / btop — 进程管理器

```shell
# 替代 top
htop

# btop 更现代，有图表和鼠标支持
btop
```

快捷键：`F4` 搜索进程、`F9` 发送信号、`F6` 排序、空格标记进程。

### du / dust / ncdu — 磁盘使用分析

```shell
# du 传统用法
du -sh *                   # 当前目录下每个项目的大小
du -sh --exclude=node_modules  # 排除 node_modules

# ncdu — 交互式磁盘分析
ncdu
# 方向键浏览，d 删除，q 退出

# dust — 更直观的 du（用树图）
dust
dust -p 3   # 只显示前三层
```

### procs — 带颜色和搜索的 ps

```shell
# 列出所有进程
procs

# 搜索进程
procs nginx
procs --or ssh

# 显示指定列
procs --no-header --sort-cpu
```

## 网络工具

### curl — HTTP 请求

```shell
# GET 请求
curl https://api.example.com/users

# 保存响应到文件
curl -o data.json https://api.example.com/users

# 显示响应头
curl -i https://example.com

# 只显示响应头
curl -I https://example.com

# 带请求头
curl -H "Authorization: Bearer token" https://api.example.com

# POST JSON 数据
curl -X POST -H "Content-Type: application/json" \
     -d '{"name":"test"}' \
     https://api.example.com/users

# 跟随重定向
curl -L https://bit.ly/short-url

# 超时设置
curl --connect-timeout 5 --max-time 10 https://example.com

# 断点续传
curl -C - -O https://example.com/large-file.zip
```

### httpie — 更友好的 curl

```shell
# 比 curl 更易读
http GET https://api.example.com

# POST JSON（默认 Content-Type 就是 JSON）
http POST https://api.example.com/users name=test email=test@test.com

# 带 token
http GET https://api.example.com "Authorization: Bearer token"

# 下载文件
http -d https://example.com/file.zip
```

### dog — DNS 查询（替代 dig）

```shell
# 查询 A 记录
dog example.com

# 指定 DNS 服务器
dog example.com @1.1.1.1

# 查询 MX 记录
dog example.com MX

# JSON 格式输出
dog example.com --json | jq
```

### iperf3 — 网络测速

```shell
# 服务端
iperf3 -s

# 客户端
iperf3 -c server_ip

# 测 UDP
iperf3 -c server_ip -u -b 100M
```

## Git 增强

### lazygit — TUI 版 Git

```shell
# 在项目目录中直接启动
lazygit
```

核心操作都在界面中完成：`1` 查看状态、`2` 查看日志、空格暂存、`c` 提交、`p` 推送。

### tig — 命令行 Git 日志浏览器

```shell
# 查看提交历史（比 git log 直观 10 倍）
tig

# 查看某个文件的修改历史
tig path/to/file

# 查看某个分支
tig feature-branch

tig blame file.py   # 查看每行最后是谁改的
```

### diff-so-fancy — 更易读的 git diff

```shell
# 配置为 Git 的 diff 工具
git config --global core.pager "diff-so-fancy | less --tabs=4 -RFX"

# 效果：彩色输出 + 忽略元数据噪音 + 更好的高亮
```

## 终端复用

### tmux — 终端会话管理器

```shell
# 启动会话
tmux

# 指定会话名
tmux new -s work

# 分离（detach）— Ctrl+B d
# 重新连接
tmux attach -t work

# 列出会话
tmux ls
```

```text
常用快捷键（前缀键 = Ctrl+B）：

  前缀 + %    → 垂直分屏
  前缀 + "    → 水平分屏
  前缀 + 方向键 → 切换窗格
  前缀 + z    → 全屏/恢复当前窗格
  前缀 + [    → 进入滚动模式（用方向键翻页）
  前缀 + c    → 新建窗口
  前缀 + n/p  → 下一个/上一个窗口
  前缀 + ,    → 重命名窗口
  前缀 + d    → 分离会话
  前缀 + s    → 选择会话
```

### zellij — 更友好的 tmux 替代

```shell
# 启动
zellij

# 模式下直接操作，不需要记快捷键：
#   Ctrl+方向键  → 切换窗格
#   鼠标直接点击
#   底部有状态栏提示
```

zellij 比 tmux 更容易上手，内置浮动终端、布局管理、无需配置即可用。

## 日常推荐清单

如果只想装几个工具就显著提升体验：

```shell
# 必装
brew install fd ripgrep fzf bat eza zoxide jq lazygit

# 强烈推荐
brew install tmux ncdu httpie dog diff-so-fancy

# 按需
brew install btop dust procs yq tig zellij moreutils
```

```shell
# 推荐配置写入 .zshrc（可选）
eval "$(zoxide init zsh)"
eval "$(fzf --zsh)"
alias ls="eza"
alias cat="bat --plain"
alias top="htop"
alias du="dust"
alias ps="procs"
```

> 这套配置的核心思路：**用更好的默认值替代老工具**。不用改变使用习惯，但每次操作都更快、输出更清晰。
