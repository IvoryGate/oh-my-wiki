# NeoVim 操作指南

> 基于 AstroNvim + rose-pine 配置

## 模式

| 模式 | 用途 | 切换 |
|------|------|------|
| Normal | 移动、删除 | `Esc` |
| Insert | 插入文字 | `i` / `a` |
| Visual | 选中文字 | `v` / `V` |
| Command | 执行命令 | `:` |

---

## 基础移动

| 命令 | 移动 |
|------|------|
| `h/j/k/l` | 左/下/上/右 |
| `w/b` | 下一个/上一个词 |
| `0/$` | 行首/行尾 |
| `gg/G` | 文件开头/结尾 |
| `{count}G` | 跳转到第 N 行 |
| `/关键词` | 搜索，`n` 下一个 |

---

## 编辑

| 命令 | 操作 |
|------|------|
| `i` | 在光标前插入 |
| `a` | 在光标后插入 |
| `o` | 在下行插入 |
| `O` | 在上行插入 |
| `x` | 删除光标字符 |
| `dd` | 删除整行 |
| `yy` | 复制整行 |
| `p` | 粘贴 |
| `u` | 撤销 |
| `Ctrl+r` | 重做 |

---

## Buffer（缓冲区）

你的配置支持 buffer 操作：

| 命令 | 操作 |
|------|------|
| `]b` | 下一个 buffer |
| `[b` | 上一个 buffer |
| `<Leader>bd` | 关闭当前 buffer |

---

## 文件操作

| 命令 | 操作 |
|------|------|
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` | 保存并退出 |
| `:q!` | 强制退出 |
| `:e 文件名` | 打开文件 |
| `:Envim` | 文件浏览器 |

---

## 搜索

### 文件内搜索

| 命令 | 操作 |
|------|------|
| `/关键词` | 正向搜索 |
| `?关键词` | 反向搜索 |
| `n` | 下一个匹配 |
| `N` | 上一个匹配 |
| `*` | 搜索光标下的词 |
| `#` | 反向搜索光标下的词 |

### 搜索选项

| 命令 | 操作 |
|------|------|
| `:set ignorecase` | 忽略大小写 |
| `:set hlsearch` | 高亮搜索结果 |
| `:nohlsearch` | 取消高亮 |
| `:set incsearch` | 增量搜索（边输入边匹配） |

### 搜索替换

| 命令 | 操作 |
|------|------|
| `:s/旧/新` | 替换当前行第一个 |
| `:s/旧/新/g` | 替换当前行所有 |
| `:%s/旧/新/g` | 替换整个文件 |
| `:%s/旧/新/gc` | 替换前逐个确认 |

## 进阶

### 宏录制

```vim
qa    " 开始录制到寄存器 a
...   " 操作
q     " 停止录制
@a    " 执行宏
@@    " 重复上次宏
```

### 重复操作

| 命令 | 重复 |
|------|------|
| `.` | 重复上次编辑 |
| `N<命令>` | 重复 N 次 |

### 块操作

| 命令 | 操作 |
|------|------|
| `Ctrl+v` | 进入块选择模式 |
| `I` | 块前插入 |
| `A` | 块后插入 |
| `d` | 删除块 |

### 搜索替换

```vim
:s/旧/新      " 替换当前行第一个
:s/旧/新/g    " 替换当前行所有
:%s/旧/���/g   " 替换整个文件
```
