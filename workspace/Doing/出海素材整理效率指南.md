# 出海素材整理效率指南

> 用 find + fzf 快速搜索和复制素材

## 核心操作

### 搜索文件

```bash
find . --type f | fzf
```

### 复制文件

```bash
cp "$(find . --type f | fzf)" /目标路径/
```

### 获取目标路径

```bash
pwd | pbcopy
```

## 工作流

```
1. 打开终端，进入素材目录
2. fzf 搜索文件，选中
3. 复制路径
4. 粘贴路径到 cp 命令

示例：
cd ~/Desktop/广告素材
cp "$(find . --type f | fzf)" ~/Desktop/本周投放/
```

## 常用搜索

| 场景 | 命令 |
|------|------|
| 搜索所有文件 | `find . --type f \| fzf` |
| 搜索视频 | `find . --type f -name "*.mp4" \| fzf` |
| 搜索图片 | `find . --type f \( -name "*.png" -o -name "*.jpg" \) \| fzf` |
| 按日期搜索 | `find . --type f -mtime -7 \| fzf` |

## 批量复制

```bash
# 复制多个文件
find . --type f | fzf -m | xargs -I {} cp {} /目标路径/
```

## 移动文件

把 `cp` 换成 `mv` 即可：

```bash
mv "$(find . --type f | fzf)" /目标路径/
```
