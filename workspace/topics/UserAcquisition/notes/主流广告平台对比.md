# 主流广告平台对比

## 平台概览

| 平台           | 类型     | 核心优势           | 计费方式         |
| ------------ | ------ | -------------- | ------------ |
| Google Ads   | 搜索+展示  | UAC 全自动投放、覆盖广、效果稳定 | CPC/CPM/CPI  |
| Meta (FB/IG) | 社交广告   | 受众广泛、再营销       | CPC/CPM/CPI  |
| Tiktok       |        |                |              |
| AppLovin     | 移动广告中台 | MAIA 智能投放、用户获取 | CPC/CPM/CPI  |
| Mintegral    | 移动广告网络 | 亚太市场优势、IAA 变现  | CPC/CPM/CPI  |
| Unity        | 游戏广告平台 | 游戏用户覆盖、IAP+IAA | CPC/CPM/CPI  |
| Moloco       | DSP 平台 | 机器学习、效果优化      | CPC/CPM/ROAS |

先做一个总结，上面的这些渠道（都是我投放过的渠道），根据个人经验做一个总结：首先Mintegral和Moloco是小渠道，一般不在首选范围中。对于大媒体渠道（Google/Meta/Tiktok），Google作为一个老牌渠道，无疑是一个很好的选择（投放效果稳定），Meta应该也是一个很不错的渠道（可惜我没有做起来过，根据听来的经验，Meta适合做平台，做深度，且素材衰减快，需要大量素材产出，此外单一计划不易放大预算，需要自动化投放工具的支持：小额预算，大量计划）。Tiktok作为一个相对新兴的大媒体渠道，其投放系统在不断发展完善当中，目前（截止行文时间）看来，还不是很稳定，且系统更新快，需要投手不断学习跟进。Applovin对于游戏投放而言是一个大平台，它需要大量的视频素材试玩素材支撑。依赖于其强劲的算法，我们只需要一股脑儿地上传素材即可，唯一的潜在问题是：当我们什么都不需要做的时候，我们似乎离失业也就不远了？Unity也是一个不错的平台，其依托于untiy游戏引擎，levelplay变现，往往也能取得不错的投放效果。

## 各平台特征

### Google Ads

- **投放类型**：应用广告系列（UAC），系统自动组合素材优化
- **展示位置**：Google 搜索、Google Play、YouTube、展示广告网络、AdMob、探索页面等
- **特点**：意图明确、高质量用户；学习周期较长（约一周）
- **素材要求**：视频质量要求高，质量差的视频跑不过图片和文字

Google 是全球覆盖最广的综合平台，核心依托用户意图+算法建模实现投放。
覆盖搜索、展示、YouTube视频、应用商店等场景。（Chrome，android，google play, gmail）。广告形式包括搜索关键词，YouTube前贴插屏，应用安装广告，展示网络广告

优点：素材生命周期长，无需爆款素材驱动。通过算法分析高转化人群，依托Google长期积累的用户行为数据，构建pCVR模型，度过学习期后投放效果稳定。

缺点：学习周期长，前期学习期成本高，学习期波动大。对于中小团队，预算有要求。对账户结构规划有要求，需要设定好转化目标，素材搭配，预算分配等。如果产品过新，搜索词可能搜不到。

官方口径补充：

- 「UAC」是旧称，官方现名「应用广告系列」（App campaigns），分安装、互动（ACe）、预注册三类
- 学习期官方建议：重大改动后需 7～14 天稳定再评估效果
- 官方版位：Google 搜索（含探索）、Google Play、YouTube、展示广告网络（Gmail、应用、资讯网站）

> 来源: [应用广告系列简介 - Google Ads 帮助](https://support.google.com/google-ads/answer/6247380?hl=zh-Hans)、[学习期时长](https://support.google.com/google-ads/answer/13020501?hl=en)

### Meta (Facebook/Instagram)
Meta Ads 是全球用户基数最大的社交广告平台，核心依托兴趣标签+素材互动数据驱动投放，属于主动找人型平台广告形式有信息流，stories,reels短视频，橱窗广告，message私信等。

底层逻辑是通过用户的社交互动数据（点赞、评论、转发、关注）推导人群喜好，即使现在隐私政策收紧，无法自定义精确定向，但是其兴趣建模的核心未变。

优势：冷启动速度快，广告上线后无需漫长学习期，只要素材优质就能快速出效果，拉量效率远高于谷歌。平台适配视觉化产品，图文，短视频，广告形式能完美呈现美妆，服饰等产品的视觉卖点。且 LAL 相似受众、再营销体系成熟，复购率高的品类能实现稳定ROI。此外，meta ads 的定向能力依然是行业顶尖，对目标用户画像清晰的产品，能够高效触达精准人群，减少流量浪费，且广告互动率高，能快速完成社交种草，为品牌积累私域流量。
缺点：素材疲劳速度极快，完全依赖爆款素材驱动，一旦素材失去吸引力，成本会快速上升，需要持续迭代优化素材，对团队的内容生产 SOP 要求极高，否则只能不断试错、碰运气。且平台无生态闭环，强依赖外部转化信号，跳转路径的细微问题（如落地页加载慢）都会大幅影响转化效果。同时，隐私政策收紧后，定向精度有所下降，人群包，兴趣标签的效果大不如前，投放策略的容错率变低；另外，meta ads的流量购买意向弱于Google，用户处于休闲社交场景，广告易被划走，若素材无法在1s内抓住用户眼球，模型会判定用户不感兴趣，停止流量推送。还有其投放效果受算法调整影响大，比如信息流推送机制变化，会导致广告曝光和转化波动，稳定性远不如Google。

官方口径补充（Advantage+ App Campaigns，原 Automated App Ads）：

- 官方主推结构为 1 个 campaign + 1 个 ad set + 多条广告，靠机器学习自动调整——「小额预算、大量计划」是 AAA 之前的传统测试打法，现状已转向单 ad set 全自动化
- 素材：一次最多上传 50 条素材 + 5 主文案 + 5 标题，官方建议每月更换 2–4 次素材（印证素材衰减快）
- 定向简化为国家/语言/应用商店组合，不支持操作系统定向

> 来源: [About Advantage+ app campaigns - Meta Business Help Center](https://www.facebook.com/business/help/309994246788275)、[Advantage+ App Campaigns - Meta for Developers](https://developers.facebook.com/documentation/app-ads/advantage-app-campaigns)

### TikTok

Tiktok 是全球增长最快的短视频广告平台，核心依托算法推荐+内容传播驱动投放，属于内容找人型平台，广告形式以信息流原生视频、开屏广告、短视频竞价广告为主，Z世代/年轻用户为核心受众，东南亚，拉美，中东等新兴市场流量优势显著，适配时尚，美妆、消费电子、游戏、快消等年轻化品类。

官方口径补充（Smart+ App Campaigns）：

- 学习期：至少跑 7 天、约 50 次转化出学习期；预算建议 ≥3 倍日常预算或 30 倍目标 CPA；素材至少 4–6 条
- 疲劳信号（官方）：CPA 翻倍或 ROAS 减半、近 2 天 CTR/CVR 下滑；对策是补新素材而非删旧素材
- Smart+ 已覆盖 App Promotion 目标，支持 tROAS/Cost Cap 出价，版位含 TikTok、Pangle、Lemon8 等；Symphony 提供 AI 素材工具——系统迭代快、需持续跟进的说法有官方印证

> 来源: [Best practices for Smart+ App Campaigns - TikTok for Business](https://ads.tiktok.com/help/article/best-practices-for-smart-plus-app-campaigns)、[Smart+ AI performance solution - TikTok for Business Blog](https://ads.tiktok.com/business/en/blog/smart-plus-ai-performance-solution)

### AppLovin

- **定位**：移动广告平台，买量核心引擎为 Axon AI，官方宣称「无需专业经验」，上传素材越多、引擎越快找到优胜组合
- **素材要求**：Creative Set 至少 1 条视频 + 1 个交互（试玩/互动页），系统自动测试组合
- **特点**：算法自动化程度极高，投手角色趋近「素材上传 + 预算管理」
- **新动向（2026）**：官方已上线多 Agent 全自动素材生成管线（交互页），自动视频/试玩生成测试中——「什么都不用做就快失业了」的调侃已有官方实锤

> 来源: [Axon by AppLovin - Founders](https://axon.ai/founders)、[Automating creative to unlock scale - AppLovin Blog](https://www.applovin.com/en/blog/automating-creative)、[Creative quick start guide - AppLovin](https://www.applovin.com/en/resources/creative-quick-start)

### Mintegral

- **定位**：Mobvista 旗下移动广告平台，UA（AppGrowth）+ 再营销 + 变现全链路，强项在休闲游戏（CrazyLabs 等案例）
- **计费与定向**：CPI/CPM/oCPM + Target-ROAS 出价；自研试玩工具 Playturbo、创意工作室 Mindworks
- **实操细节（来自库内文章，Mintegral 官方视角）**：动态出价 Campaign 基本只能定向国家；CPI 固定出价才能定向子渠道、机型、人群包——固定出价的核心价值是直接缩圈定向到目标用户
- 素材提示：视频渠道试玩展示占比应过半；各平台素材标签与召回链路不同，A 平台好素材在 B 平台不一定起量

> 来源: [Mintegral 官网](https://www.mintegral.com/en)、[[raw/articles/渠道不起量的原因都在这里了！.md]]

### Unity

- **定位**：买量侧为 Unity Ads（CPI/自动化出价/ROAS 三类 campaign），变现侧为 LevelPlay 聚合平台（整合 ironSource）；官方称美区 Top 100 畅销应用中 70 家使用其广告服务
- **ROAS campaign 开启门槛（来自库内文章）**：ROAS IAA D0 需单国家 200 个 Unity 安装 + 至少 1 个 D0 广告收入，30 天动态窗口
- **数据对账注意**：Unity 用 rolling 24h、AppsFlyer 用 calendar day 定义 D0，两边 ROAS 天然差 1–2 天，对账取 3–5 天前数据并看均值

> 来源: [Unity Ads UA](https://unity.com/products/unity-ads/user-acquisition)、[LevelPlay](https://unity.com/products/levelplay)、[[raw/articles/Unity平台ROAS开启条件和数据差异问题.md]]

### Moloco

- **定位**：机器学习 DSP，买独立 App 生态流量（非自家流量）；官方自述「与 Google/Meta 一起投，而不是替代它们」
- **门槛**：新 campaign 日预算门槛 $300，多数广告主投入更高
- **资质**：IAB Gold 2.02 认证、TAG 反欺诈认证；支持 CPI/CPA/ROAS 优化目标

> 来源: [Moloco Ads 官网 FAQ](https://www.moloco.com/moloco-ads)

### Tapjoy

- **现状**：已并入 Unity 体系（Tapjoy from Unity），核心产品变为 Offerwall（积分墙/激励市场），不再是通用竞价广告网络
- **计费**：CPE/CPA/Daily Rewards，用户完成任务才计费
- 与 Mintegral 变现侧、Unity LevelPlay 同属激励流量生态，若非积分墙打法可从对比表中移除

> 来源: [Tapjoy Offerwall - 官网](https://www.tapjoy.com/offerwall)
