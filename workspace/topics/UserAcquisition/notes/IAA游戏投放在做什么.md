# IAA 游戏投放在做什么

我们手机上安装的许多应用，都可以免费使用。比如在[红果](https://paper.people.com.cn/zgjjzk/pc/content/202412/15/content_30051899.html)，观众可以免费看短剧；在[番茄小说](https://fanqienovel.com/writer/zone/help/article)，读者也不必按章付费。那么，它们靠什么赚钱呢？这些内容吸引了观众和读者，广告主希望接触这些用户、推广自己的产品，因而愿意向平台支付推广费用。平台通过展示广告获得收入，再按约定与内容方分账。

这种模式需要兼顾几方的利益：用户希望免费看到好内容，也希望少受广告打扰。平台需要广告收入，但广告过多可能让用户离开。广告主则会根据推广效果，决定愿意付多少钱、是否继续投放。平台与内容方之间怎样分钱，又会影响创作者能否获得足够回报、是否愿意继续投入。如何在这些相互制约的诉求之间取得平衡，是这类广告业务永恒的主题。

游戏行业也有类似的商业模式。你一定或多或少接触过这样的游戏：
玩家免费下载、游玩，游戏公司通过游戏中的广告展示获得收入。这种主要依靠应用内广告赚钱的游戏，通常称为 IAA（In-App Advertising）游戏。在这里，游戏既是玩家使用的娱乐产品，也是广告主接触玩家的媒体。

而在推广自己的游戏时，游戏公司又成为了广告主。它需要在其他产品里投放广告，吸引用户下载、游玩，再从这些用户之后的活跃中获得收入。公司一面通过广告变现，一面支付广告费用获取用户，投放工作也就与这门生意的收入和成本联系起来。

> 以下为正文提纲，待逐节展开。

## 为什么花钱获取玩家

- 介绍“买量”：通过付费投放广告，吸引用户下载、游玩游戏；同时简要区分自然获取与付费推广。
- 说明经营依据：参考已有用户的表现，估计新增用户可能带来的收入，再判断获客投入是否值得。能够通过广告赚钱，并不意味着任何价格的用户都值得获取。
- 串起完整过程：推广支出 → 新增玩家 → 持续游玩 → 广告收入 → 成本回收。说明新增用户还会带来相应的运营成本。
- 承接引言的角色变化：游戏公司在变现时提供广告展示机会，在买量时则是广告主；需要分别理解两侧的收入和支出。

## 投放要考虑什么

- 获客成本与用户价值：便宜的用户未必更划算，需要结合这批用户之后能带来的收入判断。
- 回收时间与资金：广告支出发生在前，收入逐渐产生；即使预计能够收回成本，等待时间也会影响可用资金和后续投入。
- 规模与新增投入的表现：少量投放的表现不能直接推算到更大的预算；增加投入时，要继续观察新增用户的成本与价值。
- 准备一个贯穿的简单收支例子，逐步加入其他成本、回收时间和扩量后的变化。说明假设与估计，避免用一个统一门槛判断所有产品。
- 本节解释这些因素的经营含义，具体指标公式、队列分析和回收曲线留给后续篇目。

## 投放人员在其中负责什么

- 渠道与市场：决定在哪里寻找用户，比较不同来源的成本、用户表现及可获取的规模。
- 素材：把游戏呈现给潜在玩家，观察广告吸引来的人是否适合产品，为后续创作提供反馈。
- 优化目标、出价与预算：将公司的回收要求转化为投放选择，结合数据调整投入；本篇只解释各项决策的作用，不展开平台设置。
- 观察与验证：跟踪实际消耗和用户后续表现，检查预期是否成立，再决定继续、调整或停止投入。
- 收束本节目标：在公司的回收要求下，持续获取有价值的用户，并判断还有多大的增长空间。

## 投放与其他工作的关系

- 产品体验影响玩家是否愿意留下，广告变现影响展示机会如何转化为收入，数据工作影响结果能否被正确记录和判断。
- 说明投放与产品、素材、变现、数据等工作的协作，不将留存或收入变化直接归因于某一个岗位。
- 交代自投与代投：执行者可以是游戏公司的内部团队，也可以是代理公司；合作中的目标、考核、权限与信息需要明确，双方利益不能默认完全一致。
- 回应开头的利益关系：获取用户、维持体验、提供广告效果、获得经营收入需要共同考虑；投放决策应放回这套经营关系中评估。
