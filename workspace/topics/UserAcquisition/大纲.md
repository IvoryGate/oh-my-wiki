## 第一部分：基础概念——投放到底在做什么

- [ ] **1. 投放的全局链路与核心矛盾**
  - 核心链路：曝光 → 点击 → 安装 → 游戏行为 → 留存 → 变现 → LTV → ROAS → 扩量/止损
  - 投手的最终目标：在目标回收要求下把规模做大；Efficiency vs Scale 的张力
  - 成本最低 ≠ 最好，ROAS 最高但花不出去也不最有价值
  - 已有：广告投放问答 Q1/Q20、主流广告平台对比开篇
- [ ] **2. 游戏变现模式：IAA / IAP / IAAP**（变现侧资料待补）
  - IAA 链路（活跃→展示→收入）、指标（Ads/DAU、eCPM、ARPDAU）
  - IAP 链路（留存→深度系统→付费）、指标（付费率、ARPPU）
  - 混合变现：LTV = Ad LTV + IAP LTV，Blended ROAS
  - Rewarded 的两种角色：变现层 vs 游戏经济系统的一部分（看广告刷新角色/加位/拿资源），及新增关注点（Rewarded 参与率、看广告后是否推进、Rewarded 用户留存与付费）
  - 已有：UA基础知识扫盲、出海IAA休闲游戏投放
- [ ] **3. 投放漏斗指标：CPM / CTR / CVR / CPI / IPM**
  - 每个指标看什么；CPI = CPM / (CTR × CVR × 1000) 的成本拆解
  - CPI 上涨先拆：CPM↑？CTR↓？CVR↓？
  - 已有：UA基础知识扫盲、广告投放问答 Q21
- [ ] **4. 价值与留存指标：ROAS / ARPU / ARPPU / ARPDAU / LTV / Retention**
  - D0~D180 ROAS 的周期意义；D7 留存的定义陷阱（第 7 天活跃，非 7 天内回访过）
  - 留存为什么是 IAA/IAP 的共同根因
  - 已有：广告投放问答 Q6–Q10、DAU-Retention-Rate、Session-Tracking
- [ ] **5. 回收曲线与阶段 KPI**
  - D0 高 ≠ 最终价值高；短期 ROAS = 现金流速度，长期 ROAS = 盈利能力
  - 用历史 cohort 曲线倒推 D0/D3/D30 阈值（阶段 KPI 的由来）
  - 已有：广告投放问答 Q7/Q8、Cohort-Analysis
- [ ] **6. 队列分析 Cohort**
  - 定义、跨渠道长期质量对比、成熟度与预测边界
  - 已有：Cohort-Analysis、raw《什么是Cohort队列》、ROAS-Data-Reconciliation

## 第四部分：实操方法——怎么投

- [ ] **12. 扩量与预算经营**
  - 纵向（加预算/放宽约束）与横向（新素材/地区/受众/渠道）
  - 边际 ROAS：平均 ROAS 骗人，扩量买的是边际流量
  - 渠道组合与预算动态分配（早期现金 vs 长期质量，一般化原则）
  - 已有：广告投放问答 Q22、出海IAA休闲游戏投放（季节节奏）、主流广告平台对比「选择建议」
- [ ] **13. 素材方法论**
  - 完整评价链：CTR→CVR→CPI→留存→ROAS/LTV（素材对业务结果负责）
  - Quality × Scale 二维评价；四种组合的处理
  - CTR 高 ROAS 差 / CTR 低 ROAS 好的判别；衰退链路（Frequency↑→CTR↓→IPM↓→CPI↑）与「复制机制不复制文件」
  - Playable 的筛选价值与玩法不一致风险
  - 新素材两阶段测试；智能投放 ≠ 严格 A/B（样本量、成熟度、随机分流）
  - 已有：主流广告平台对比「素材拆解」、广告投放问答 Q16–Q19、raw《渠道不起量》素材节；二维模型与两阶段阈值属提纲新增
- [ ] **14. 数据诊断框架**
