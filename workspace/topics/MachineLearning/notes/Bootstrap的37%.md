# Bootstrap 的 37%：一个数字背后是整个集成学习的根基

Bootstrap 有放回抽样 n 个样本（n 为原始数据集大小），某个样本始终不被抽到的概率趋近于 $1/e \approx 0.3679$。这个 37% 看似一个简单的概率题答案，但它像一根线，串联了从统计推断到集成学习的一系列核心概念。

## 为什么是 1/e？

一个样本在一次抽取中被抽中的概率是 $1/n$，不被抽中的概率是 $1 - 1/n$。独立抽 n 次都不被抽中：

$$P(\text{不被抽中}) = (1 - \frac{1}{n})^n$$

当 $n \to \infty$ 时，这个表达式趋近于 $1/e$。实际上对大多数数据集（$n \ge 100$），值已经很接近 37% 了。

换个更自然的视角：每个样本在 n 次抽取中被抽中的次数服从 **Poisson(1) 分布**。期望次数为 1，恰好被抽中 k 次的概率为 $1/(k! \cdot e)$。所以 P(从未被抽中) $= 1/(0! \cdot e) = 1/e$。

## 含义一：每次只用 63% 的数据

每次 Bootstrap 采出的 n 个样本中，**不重复的样本数**的期望值是：

$$\lim_{n\to\infty} E[\text{unique}] = n \cdot (1 - \frac{1}{e}) \approx 0.632n$$

也就是说每棵树只用了约 63% 的原始数据。这本身就是一种天然的随机性——它保证了每棵树的训练集都不同，从而产生多样性。这正是集成学习的核心：**合而不同**。

## 含义二：OOB 误差 ≈ 留一法交叉验证

每个样本平均在 37% 的树上是"包外"的（没有被那棵树看到）。当我们收集所有包的样本预测结果时，对于一个样本，我们有大约 $0.37 \times B$ 棵树的预测（B 是森林大小）。取这些预测的平均值，就得到了这个样本的 OOB 预测。

OOB 误差的特殊之处在于：

| 评估方法 | 偏差 | 方差 | 计算成本 |
|---------|------|------|---------|
| 训练集误差 | 严重低估（高偏差） | 低 | 免费 |
| 独立测试集 | 无偏 | 高 | 需要额外数据 |
| K 折交叉验证 | 近似无偏 | 中 | O(K) 倍训练 |
| **OOB 误差** | **近似无偏** | **低** | **几乎免费** |

OOB 不用额外划分数据，不增加训练成本，却能给出近乎无偏的泛化误差估计。对于大型随机森林，OOB 误差和 K 折交叉验证的结果高度一致。这是 37% 带来的意外馈赠。

## 含义三：连接统计推断和机器学习

Bootstrap 最初并不是为机器学习发明的——它来自 Efron 1979 年的统计学论文，目的是在不做分布假设的情况下估计统计量的标准误。

传统统计需要假设数据来自某个分布（如正态），然后推导统计量的抽样分布。Bootstrap 的思路截然不同：**用计算替代假设**——把原始数据当作总体，反复从中重采样，直接观察统计量的变化。

随机森林把 Bootstrap 从"估计工具"变成了"多样性引擎"。37% 在统计学里告诉你估计有多稳，在集成学习里告诉你多样性从哪来。同一个数字，两种角色。

## 含义四：37% 多了还是少了？

直觉上，每棵树只用 63% 的数据好像太浪费了。但换个角度看：

- 如果用 100% 的数据 + 全部特征 → 所有树长得几乎一样 → 集成几乎没有提升
- 如果用 63% 的数据 + 随机特征 → 树之间差异大 → 集成后方差大幅降低

Breiman 在 2001 年的随机森林论文中证明，随机森林的泛化误差上界随着树间相关性的降低而降低。63% 的数据复用一个简单的随机化策略，恰好是一个在"多样性"和"个体准确率"之间的平衡点：

- 数据比例太低 → 每棵树太弱 → 集成后偏差过高
- 数据比例太高 → 树之间太相似 → 集成后方差降不下来

63%（而非 50% 或 80%）来自数学：$1 - 1/e$ 是被自然定义的，不是人为调出来的参数。这是少有的"参数由数学决定而非凭经验调优"的例子。

## 总结

| 视角 | 37% 的深层含义 |
|------|--------------|
| 数学 | $n$ 次独立抽取的极限分布，Poisson(1) 的自然推论 |
| 集成学习 | 保证每棵树只用 63% 的数据，创造多样性 |
| 模型评估 | OOB 样本是免费的验证集，近似无偏 |
| 统计推断 | Bootstrap 用计算替代分布假设 |
| 算法设计 | 多样性/准确率的天然平衡点，不是人工调参的结果 |
