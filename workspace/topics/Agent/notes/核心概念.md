# Agent 核心概念

> 基于现有 wiki 概念的整理

## 核心循环 (Agent-Loop)

Agent 是有循环的系统：感知 → 决策 → 行动 → 反馈

相比 Workflow（无循环、确定性执行），Agent 的核心特征是**自主决策**。
